# Claude Finance

基于 Claude Code 的投资分析工作区。

## 内容

`.claude/skills/` 下的评估/筛选 skill：

- `munger-eval/` — 芒格公司评估：四层过滤器（能力圈、护城河、管理层、估值与安全边际）评估一家公司是否值得长期持有，适用于传统价值股（消费、工业、金融）
- `power-eval/` — 科技公司权力评估：munger-eval 的科技版对位。先做公司类型分档，再以六层过滤器（生意与 S 曲线定位、七种权力、增长质量与单位经济、创始人与资本配置、颠覆与依赖风险、反向 DCF 估值）检验，结构层否决 + 增长/估值层降级
- `call-eval/` — 看涨期权做多筛查（1–2 个月窗口）：宏观过滤 + 五层否决制（趋势、基本面、催化剂、回调/稀释、期权赔率）
- `short-eval/` — 看跌期权做空筛查：call-eval 的镜像，按"上涨慢于下跌"做了权重修正
- `trade-eval/` — 方向裁决器：跑完 short/call 两向后对比裁决"做多 / 做空 / 观察 / 不操作"
- `chokepoint-screen/` — 卡脖子零部件筛选（收费站/卖铲人）：面向一条产业链（内置 AI 机器人价值链），以五层否决制找"最像海力士/台积电位置"的高壁垒寡头供应商，输出分层候选清单

`output/` — 各 skill 的报告输出目录（按 skill 名分子目录）。

## 使用

在本目录下启动 Claude Code，然后用自然语言触发对应 skill，例如：

```
用芒格的方法分析一下 <公司名>
用七种权力分析一下 <科技公司>，当前股价隐含了什么假设
帮我看看 <股票> 现在该做多还是做空
找出 AI 机器人产业链里最像海力士位置的美股和日股公司
```

报告会生成到 `output/<skill 名>/<标的或赛道>-<日期>.md`。
