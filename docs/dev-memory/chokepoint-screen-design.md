# chokepoint-screen 设计记忆

记录 `chokepoint-screen`（卡脖子/收费站零部件筛选）skill 的非显而易见设计决策，供后续维护与复用。代码结构本身见 `.claude/skills/chokepoint-screen/`，此处只记"为什么这么设计"。

## 1. 框架是通用的，机器人只是内置默认赛道

- skill 的过滤器（F1–F5）是**通用的"海力士/收费站位置"结构选股框架**，AI 机器人价值链只作为内置领域包（`references/value-chain-map.md`）。
- 为什么：可迁移到任何产业链（换一份 value-chain-map 即可），避免把逻辑写死在机器人上。用户换赛道时，F0 需临时构建价值链，F1–F5 不变。

## 2. 把"海力士位置"拆成五条可检验基因 → 五层否决制

- 五基因：① 横向非纵向 ② 卡脖子瓶颈 ③ 寡头 ④ 能变现（不是有份额没利润）⑤ 抗颠覆。对应 F1–F5。
- **F5 是本框架区别于普通护城河分析的关键**：它内置两个"专杀收费站的敌人"——**整机厂垂直整合**（机器人不像 GPU，大整机厂有动机自研电机/丝杠/执行器）与**国产低价替代**（把垄断份额打成微利）。这两条是否决项，不是降级项。
- 沿用仓库既有约定：否决制（非加权平均）、证据驱动、emoji 判定标识（✅🚨⚠️❓❌）、references/ 明细 + assets/ 模板 + 输出到 `output/<skill>/`，与 munger-eval / short-eval 一致。

## 3. "英伟达位置" vs "海力士位置" 显式分离

- 算力+软件生态层（如 Nvidia Jetson/Isaac/GR00T）是另一种收费站（生态锁死），逻辑不同于实体零部件寡头。skill 要求把命中"英伟达位置"的公司**单列**，不与实体零部件寡头混排评分，避免用不同护城河逻辑的标的互相污染排名。

## 4. 纯度门允许"核心候选=空集"，这是特性不是 bug

- F5-纯度是降级门：机器人/目标环节营收占比太低（被其他业务稀释）→ 至多"观察"。
- 2026-07-21 首次跑 AI 机器人赛道（美股+日股）时，核心候选为空集——因为所有上市标的的机器人营收当期都是"期权/叙事"，且最纯的卡脖子环节（行星滚柱丝杠、高精度编码器、触觉皮肤）在美股/日股买不到干净标的（私有/A股/英股）。
- 这是框架相对"追热点选股"的**差异化价值**：宁可给空集 + 排序好的"观察"层，也不把摊薄的集团或题材股伪装成核心。维护时不要为了"给个答案"而放松纯度门。

## 5. 数据来源分工

- 首跑用 3 个并发子代理（Opus）分头核实：日股精密机电、美股运动/感知、各环节市场结构与威胁评级。份额/规模来自第三方聚合机构（方向性，标 ❓）；上市状态/股权/财报核对至一手 IR/SEC/TDnet。
- 复用时务必重新联网核实份额与财报（时效性强），不要沿用本次数字。
