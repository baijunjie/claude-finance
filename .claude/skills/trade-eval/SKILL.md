# 交易方向裁决（Trade Eval）

输入一只股票，输出一个明确的方向结论：**做多（买 call）/ 做空（买 put）/ 观察 / 不操作。** 做法是把 [short-eval](../short-eval/SKILL.md) 与 [call-eval](../call-eval/SKILL.md) 两个方向各跑一遍完整评估，再做对比裁决——不另立新理论，只做编排与综合。

## 核心逻辑：方向互斥 + 严格否决

- **方向互斥**：F1 趋势确认是做空（需下降趋势）与做多（需上升趋势）各自的硬必要条件，而一只股票同一时刻只有一种趋势。因此**严格否决制下最多只有一个方向能通过**——这正是"两个都跑"的价值：看清被否方向到底卡在哪一关。
- **严格否决，不勉强表态**：只有某方向的完整评估给出可执行结论（short 的"做空" / call 的"买入"）时，才输出该方向。两个方向都"放弃"→ **不操作**；某方向论点成立但被降级 → **观察（注明偏向与待满足条件）**。绝不为了"给个方向"而勉强交易。
- **共享数据，单向解读**：宏观（F0）与基本面等数据只采集一遍，但分别用做空与做多两副镜片解读（risk-off / 坏公司 → 利空；risk-on / 上涨引擎 → 利多）。

## 工作流程

### 第 0 步：识别标的与共享数据收集

- 解析用户给的股票名称或代码，确认唯一标的（含交易所、币种）。歧义时先与用户确认。
- 一次性收集**两个方向共用**的数据，覆盖 short-eval 与 call-eval 各自第 0 步所需：宏观环境（F0）、价格与趋势、基本面（既算坏公司指标也算上涨引擎指标）、双向催化剂日历、期权链/IV/skew、空头与拥挤度、稀释与解禁。数据缺口标 ❓。

### 第 1 步：做空方向评估（执行 short-eval）

执行 [short-eval](../short-eval/SKILL.md) 的完整流程（F0 宏观 → F1 下降趋势 → F2 坏公司 → F3 催化剂 → F4 逼空/反弹 → F5 期权赔率 → Pre-mortem/退出），按其评分与否决规则得出**做空结论**：做空 / 观察 / 放弃，并记录否决/降级原因与关键证据。子备忘录按 short-eval 约定保存到 `output/short-eval/<标的>-<日期>.md`。

### 第 2 步：做多方向评估（执行 call-eval）

执行 [call-eval](../call-eval/SKILL.md) 的完整流程（F0 宏观 → F1 上升趋势 → F2 基本面向好 → F3 催化剂 → 上涨引擎判定 → F4 回调/稀释 → F5 期权赔率 → Pre-mortem/退出），按其评分与否决规则得出**做多结论**：买入 / 观察 / 放弃，并记录否决/降级原因与关键证据。子备忘录按 call-eval 约定保存到 `output/call-eval/<标的>-<日期>.md`。

### 第 3 步：方向裁决（严格否决制对比）

按下表综合两个方向的结论：

| short-eval 结论 | call-eval 结论 | 最终裁决 |
|----------------|---------------|---------|
| 做空 | 放弃 | **做空**（买 put） |
| 放弃 | 买入 | **做多**（买 call） |
| 放弃 | 放弃 | **不操作**（无趋势或两向皆不达标） |
| 观察 | 放弃 | **观察（偏空）**——注明待满足条件 |
| 放弃 | 观察 | **观察（偏多）**——注明待满足条件 |
| 观察 | 观察 | **不操作 / 观察**——两边都不够格，注明哪边更接近 |
| 做空 | 买入 | 🚨 **数据矛盾**：趋势不可能同时确认双向，回查两边 F1 与数据口径，不出结论 |

裁决原则：
- 可执行结论（做空/买入）优先于观察，观察优先于放弃；但**绝不**把"放弃"升格为方向结论。
- 若裁决为"做空/做多"，复述该方向 F5 的期权结构建议（DTE、行权价、赔率）与退出计划。
- 若裁决为"观察/不操作"，写明两个方向各自的首要否决/降级原因，以及触发复评的条件。

### 第 4 步：输出裁决备忘录

按 [assets/verdict-template.md](assets/verdict-template.md) 生成裁决备忘录，保存到 `output/trade-eval/<标的>-<日期>.md`（目录不存在时先创建）。备忘录含：一句话结论、双向对比表、被否方向的卡点、可执行方向的操作要点，并指向第 1/2 步保存的两份完整子备忘录。

**判定标识**（沿用子 skill 体系）：✅ 有利/通过 ｜ 🚨 不利/否决项 ｜ ⚠️ 存疑/降级 ｜ ❓ 数据缺口 ｜ ❌ 不通过/无。

## 注意事项

- 这是**短期（1-2 个月）、买入期权、不持有到期、找点位平仓**的方向裁决器，依赖 short-eval 与 call-eval；不适用于长期持有（用 munger-eval）、套利、财报当天博弈
- 两个方向的评分细则、理论依据、Pre-mortem 与退出计划完全沿用各自子 skill，本 skill 只做编排与对比，不改写子 skill 的判定标准
- 如果用户一次给出多只标的，逐只独立裁决后再给汇总表
- 期权、宏观、空头与稀释数据时效性强，正文引用处标注数据时间，缺失标 ❓
