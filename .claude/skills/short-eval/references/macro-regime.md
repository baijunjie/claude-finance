# 宏观环境过滤器（Filter 0）

F0 在所有自下而上的过滤器（F1-F5）**之前**执行——先看宏观大势，再选个股。它有三个角色：**① 顺风/逆风确认；② 可选的左侧宏观引擎（带护栏）；③ 宏观对已确认趋势的终结风险。** 做空方向上，**risk-off / 紧缩 / 流动性收紧 = 顺风**。每项判定须给具体数据（指数点位、利差 bp、VIX 水平、政策日期），禁止用形容词代替。

## 1. 三个角色与核心规则

- **角色一 · 顺风/逆风确认（始终执行）**：判断宏观制度是否支持做空方向。risk-off、紧缩、信用利差走阔、市场宽度恶化、VIX 抬升 = ✅ 顺风；risk-on 普涨、宽松放水、流动性 melt-up = 🚨 逆风。
- **角色二 · 左侧宏观引擎（可选，带护栏）**：允许把宏观拐点作为论点驱动与催化剂（喂给 F3），但**个股 F1 趋势仍须至少初步确认**——宏观+趋势共振才行，**宏观单独不能覆盖 F1 否决**（见第 3 节）。
- **角色三 · 趋势终结风险（始终执行）**：评估窗口内宏观事件是否会**终结当前下降趋势**（如鸽派转向引爆普涨），并喂给 Pre-mortem（见第 4 节）。

**核心规则（短）：**
- 宏观顺风 → F1-F5 正常推进，赔率加分；
- 宏观**强逆风**（明确反向 + 个股高 beta）→ 否决或降级，哪怕个股趋势/基本面再好；
- 宏观可作左侧引擎，但**绝不**单独成为入场理由，F1 仍是硬否决项。

## 2. 宏观环境核查清单（1-2 个月窗口）

| 维度 | 做空顺风信号（risk-off） | 做空逆风信号（risk-on） |
|------|----------------------|----------------------|
| 大盘趋势 | 标普/纳指/相关指数处下降趋势、跌破 200 日线 | 指数创新高、强多头排列 |
| 市场宽度 | % above 200dma 走低、A/D 线背离、新低扩张 | 宽度健康、普涨 |
| 货币/流动性 | 加息/缩表、实际利率上行、流动性收紧 | 降息/放水、宽松预期升温 |
| 收益率曲线 | 深度倒挂后转陡（衰退临近信号） | 健康陡峭、增长预期改善 |
| 信用利差 | HY OAS 走阔（风险偏好恶化） | 利差收窄 |
| VIX 制度 | VIX 抬升/期限结构倒挂（恐慌） | VIX 低位平静 |
| 美元/大宗 | 美元走强（紧缩、避险）、油价异动 | 美元走弱、风险资产普涨 |
| 板块/风格 | 标的所属板块相对走弱、防御跑赢周期 | 成长/周期领涨、板块强势 |

并列出**窗口内宏观日历**：FOMC、CPI/PCE、NFP、央行会议、GDP、地缘/政策事件——标注日期是否落在期权到期前。

## 3. 左侧宏观引擎的护栏（"允许左侧但趋势仍必要"）

若要用左侧宏观判断（在普跌确认前提前布局），必须同时满足：
1. **锚定到带截止日的触发**：把开放式观点转成可证伪事件，如"6/15 CPI > X% → 紧缩重定价 → 该周期股补跌；put 7 月到期"，而非"经济要衰退了"。
2. **跨资产确认**：至少 2 个独立跨资产信号同向（如曲线 + 信用利差 + VIX），不凭单一宏观观点。
3. **F1 趋势仍须初步确认**：个股至少出现转弱结构（如 F1 的"有条件通过"），宏观负责把时间线压进窗口——**宏观看空 + 个股仍在上升趋势 = 仍然不做**。
4. **护栏式下单**：减小仓位、选更长 DTE 或用价差（put spread），以扛住"早"。

## 4. 宏观对已确认趋势的终结风险

即使 F1 已确认下降趋势，也要问：**窗口内有没有宏观事件可能逆转它？**
- 典型终结源：央行意外鸽派/降息、政策强刺激、紧缩周期见顶预期、超预期利好数据引发空头回补共振、地缘风险缓和。
- 处理：把"宏观逆转终结下降趋势"列为 Pre-mortem 的失败路径之一并估概率；若该宏观事件临近且方向高度不确定（如 FOMC 前夜），考虑等事件落地或降级为观察。

## 5. Beta / 相关性：宏观主导还是个股 alpha 主导

- 个股与大盘**相关性高（高 beta）** → 宏观主导，F0 权重大，逆风时务必否决/降级。
- 相关性低、个股有独立基本面崩坏逻辑（强 F2）→ 个股 alpha 主导，可适度容忍中性偏逆风的宏观，但仍不可顶风（强逆风）硬做。
- 在备忘录注明该标的当前的 beta / 与大盘相关性，作为 F0 权重依据。

## 6. F0 判定锚点

| 判定 | 标准 |
|------|------|
| ✅ 顺风 | 多数核查维度指向 risk-off/紧缩，或有锚定到窗口内事件的左侧做空逻辑 + 跨资产确认 |
| ⚠️ 中性 | 宏观信号混杂、无明确方向，或个股低 beta 受宏观影响小 → F0 不加不减，按 F1-F5 推进 |
| 🚨 逆风 | 明确 risk-on/宽松普涨 + 个股高 beta → 否决或降级（顶风做空胜率低）；或窗口内有大概率终结下降趋势的宏观事件 |

**评分依据**：列出关键宏观数据与窗口内日历，说明判为顺风/中性/逆风的理由，以及是否启用了左侧引擎（启用则列出护栏落实情况）。
