# 坏公司基本面红旗清单（Filter 2）

Filter 2 的详细检验标准。核心问题：**这是不是一家真正的"坏公司"——财务困境、低质量、或盈余操纵？** 每一项判定都必须给出具体数据，禁止用形容词代替证据。注意：**估值高不是做空理由**（高估能持续多年），它只是 F1 趋势开始压估值后的"下行空间放大器"。

## 1. 理论基础

- **困境风险异象（Campbell, Hilscher & Szilagyi, 2008）**：财务困境程度最高的股票，长期、风险调整后**显著跑输**——是"做空坏公司"最直接的学术背书。
- **质量因子 / Quality Minus Junk（Asness, Frazzini & Pedersen）**：低质量（低盈利、低成长、不安全、不稳定）的"junk"股票系统性跑输高质量股票。
- **应计异象（Sloan, 1996）**：高应计利润（净利润远超经营现金流）预示未来低回报，因为应计部分质量低、不可持续。

做空的基本面标的，应该在这些维度的**反面**得分突出。

## 2. Altman Z-Score（破产距离）

原始制造业模型（1968）：

```
Z = 1.2·X1 + 1.4·X2 + 3.3·X3 + 0.6·X4 + 1.0·X5
```

| 变量 | 含义 |
|------|------|
| X1 | 营运资本 / 总资产 |
| X2 | 留存收益 / 总资产 |
| X3 | EBIT / 总资产 |
| X4 | 股权市值 / 总负债账面值 |
| X5 | 营收 / 总资产 |

判定区间：
- **Z > 2.99**：安全区 ✅（不利做空）
- **1.81 ≤ Z ≤ 2.99**：灰色区 ⚠️
- **Z < 1.81**：困境区 🚨（破产风险高，做空有利）

注意：原始模型针对制造业。非制造业/新兴市场用 Z''（`Z'' = 3.25 + 6.56·X1 + 3.26·X2 + 6.72·X3 + 1.05·X4`，阈值：> 2.6 安全，< 1.1 困境）。选用哪个版本须在备忘录注明，并标注计算所用财报期。

## 3. Beneish M-Score（盈余操纵概率）

8 变量模型，识别**通过应计与确认手法粉饰利润**的公司：

```
M = -4.84 + 0.920·DSRI + 0.528·GMI + 0.404·AQI + 0.892·SGI
      + 0.115·DEPI − 0.172·SGAI + 4.679·TATA − 0.327·LVGI
```

| 指数 | 含义（多为本期 / 上期之比） |
|------|------|
| DSRI | 应收账款周转天数指数（应收/营收的变化） |
| GMI | 毛利率指数（毛利率下滑则 > 1） |
| AQI | 资产质量指数（非流动非固定资产占比变化） |
| SGI | 销售增长指数 |
| DEPI | 折旧率指数 |
| SGAI | 销售管理费用指数 |
| TATA | 总应计利润 / 总资产 |
| LVGI | 杠杆指数 |

判定：**M > −1.78 → 可能存在盈余操纵 🚨**（越高越可疑）。

需两期财报明细，数据较重。数据不足时退回第 8 节简化红旗，并标注 ❓。

## 4. Piotroski F-Score（财务健康度，做空看低分）

0-9 分，9 项二元指标（满足记 1 分），分布在三类。**做空标的应得低分（0-3 = 财务孱弱 🚨）。**

- **盈利能力**：ROA > 0；经营现金流 > 0；ROA 同比上升；经营现金流 > 净利润（应计质量）
- **杠杆/流动性**：长期负债率同比下降；流动比率同比上升；未增发新股稀释
- **运营效率**：毛利率同比上升；总资产周转率同比上升

低分意味着盈利在恶化、靠借钱/增发续命、运营效率下滑——典型做空画像。

## 5. Sloan 应计利润（盈利质量）

```
应计利润率 = (净利润 − 经营现金流) / 总资产
```

- 应计利润率**高且为正** 🚨：利润里"纸面"成分大、现金含量低，未来回报倾向走低。
- 配合检查：净利润持续增长但经营现金流长期跟不上（CFO/净利润 < 70% 连续 ≥ 2 年）。

## 6. 结构性恶化与商业模式终局

定性但关键，逐条判定"存在 / 不存在 / 存疑"：
- **商业模式终局**：核心产品被替代、需求结构性萎缩、单一爆款过气、监管/技术变迁摧毁盈利来源
- **行业结构性衰退**：整个行业量价齐跌、产能过剩、被新技术降维打击
- **份额与定价权流失**：市占率持续下滑、靠降价/促销维持销量、毛利率连续多季压缩
- **资产负债恶化**：有息负债攀升 + 利息保障倍数下降 + 再融资窗口收窄（高利率环境下尤其致命）

## 7. 戴维斯双杀（下行空间的放大机制）

回答"如果跌，能跌多深"：当**盈利下修**与**估值倍数压缩**同时发生，跌幅是两者相乘：

```
跌幅 ≈ 1 − (EPS_new / EPS_old) × (PE_new / PE_old)
```

例：EPS 下修 20%、PE 从 30 压到 20（−33%）→ 股价 ≈ 0.8 × 0.67 − 1 = −46%。

做空最理想的标的：**高估值 + 盈利拐头向下**，双杀同时启动；此时高估值才真正转化为下行空间（呼应"估值是放大器不是理由"）。

## 8. 简化红旗清单（数据不足以算分时的回退）

任意命中多条即构成"坏公司"倾向，逐条标注：
- 经营现金流长期跟不上净利润（CFO/净利润 < 70%）
- 应收账款/存货增速持续显著高于营收增速
- 毛利率/经营利润率连续多季下滑
- 净有息负债/EBITDA > 3 倍，或利息保障倍数 < 2
- 大存大贷、频繁更换审计师、复杂关联交易、激进收入确认
- 管理层/大股东高位密集减持，股权质押比例高
- 反复"一次性"减值/重组、频繁修改会计估计

## 9. F2 评分锚点（0-10，越高越是"理想做空标的"）

| 分数 | 标准 |
|------|------|
| 9-10 | Z < 1.81（困境）+ M > −1.78（疑操纵）+ F-Score 0-2 + 结构性衰退明确 + 戴维斯双杀在途 |
| 7-8 | 多个量化模型指向坏公司（如 Z 灰区偏低 + F-Score ≤ 3 + 现金流/应计红旗），结构性恶化清晰 |
| 6 | 基本面确有恶化迹象但证据单一或刚开始（及格线：勉强算"坏公司"） |
| 4-5 | 平庸公司，估值贵但基本面没有明显恶化（"只贵不坏"，不构成做空理由） |
| 0-3 | 基本面稳健或在改善（坚决不做空，哪怕趋势暂时走弱） |

**评分依据须对照本表锚点**，说明各量化分数与红旗如何得出该分；无 ≥ 2 个独立维度（困境/操纵/结构）支撑的，最高给 5 分。
