# 趋势确认标准（Filter 1）

Filter 1 的详细判定标准。核心：**只在确认的中期下降趋势中做空，绝不抓拐点、绝不做空上升趋势。** 每一项判定都必须给出具体证据（价位、均线值、相对强弱数据），禁止用"走势弱"之类形容词代替证据。

## 1. 理论基础

- **道氏理论（Dow Theory）**：趋势由连续的更高高点/更高低点（上升）或更低高点/更低低点（下降）定义；趋势一旦确立倾向于延续，直到出现明确的反转信号；次级回调不改变主趋势。
- **横截面动量异象（Jegadeesh & Titman, 1993）**：过去 3-12 个月的"输家"组合在随后数月continue跑输——做空中期输家在统计上有正期望。
- **时间序列动量 / 趋势跟踪（Moskowitz, Ooi & Pedersen, 2012）**：资产自身近 3-12 个月的回报方向对未来有预测力，是全球 CTA 趋势跟踪策略的学术基础。
- **移动平均规则（Faber, 2007）**：以价格相对长期均线（如 200 日）的位置作为持有/离场信号，可改善风险调整后回报。

这些共同支撑本模型的立场：**做空已在中期下跌通道中的标的，比预测高位股的拐点风险低得多。**

## 2. 道氏理论：趋势结构判定

核心问题：**近 3-6 个月是否形成连续更低的高点 + 更低的低点？**

| 判定 | 标准 |
|------|------|
| ✅ 确认下降 | 至少 2 个依次降低的波段高点 + 2 个依次降低的波段低点；反弹被前低/均线压制 |
| ⚠️ 转弱未确认 | 刚跌破重要颈线/前低但尚未回踩确认，或高点开始走低但低点未破 |
| ❌ 非下降 | 更高的高点/更高的低点（上升趋势），或高低点交错无方向（宽幅震荡） |

辅助确认：下跌伴随放量、反弹缩量（量价配合）；跌破关键支撑（前期平台、颈线、整数关口）。

## 3. 均线与位置判定

- **价格位置**：收盘价是否在 200 日均线**下方**？距离多少百分比？（越深越确认，但过深需结合 F4 防超卖反弹）
- **均线排列**：50 日均线是否在 200 日均线下方（空头排列 / 死叉已发生）？均线是否走平转向下？
- **52 周位置**：是否接近 52 周低点区间？（52 周低点附近的股票倾向于continue弱势——52 周高低点异象）

合格的下降趋势通常满足：价 < 200 日线，且 50 日 < 200 日，且均线向下发散。

## 4. 相对强弱与动量判定

- **相对大盘**：近 3 / 6 个月相对基准指数（标普、日经等）是否持续跑输？
- **相对板块**：是否跑输所属行业板块？（个股弱 + 板块弱 = 更强的做空环境）
- **动量形成窗口**：用 **3-6 个月**回报判断趋势方向，而不是最近 1 个月（原因见第 5 节）。

## 5. 一个关键细节：短期反转 vs 中期动量

学术上有个反直觉但必须知道的事实：
- **1 个月以内**是**短期反转**（Jegadeesh, 1990; Lehmann, 1990）——上月大跌的股票下月倾向于反弹；
- **3-12 个月**才是**动量延续**。

对本模型的两条直接含义：
1. **判定趋势用中期窗口**（3-6 个月 / 200 日均线），"上个月跌很多"本身不构成下降趋势，反而可能是反弹前兆。
2. 你持有的 1-2 个月窗口恰好落在短期反转高发区——这正是 F4 必须单列"反弹/逼空风险"的理论原因，也解释了"找点位平仓而非持有到期"的合理性：在反弹来临前兑现。

## 6. 反例：什么不算"确认的下降趋势"

以下情形 F1 一律判 ❌ 或 ⚠️，不得做空：
- **上升趋势中的高估股**：哪怕泡沫巨大、基本面差——上升趋势可持续数年，做空它是抓拐点（本模型明确否定）。
- **宽幅震荡 / 箱体**：无明确方向，put 会被 theta 慢慢磨掉。
- **单日/单周暴跌后的恐慌低点**：极度超卖，技术性反弹概率高（短期反转），应等反弹乏力、趋势重新确认后再评估。
- **下降趋势末端的恐慌抛售**：可能临近阶段性底，赔率差，归入 F4 反弹风险评估。

## 7. F1 判定锚点

| 判定 | 标准 |
|------|------|
| ✅ 通过 | 道氏结构确认下降（更低高低点）+ 价在 200 日线下方 + 50 日 < 200 日 + 近 3-6 个月跑输大盘/板块；且当前非极度超卖 |
| ⚠️ 有条件通过 | 趋势刚转弱（如初次跌破颈线/前低，或均线刚死叉）但结构未完全确认——须写明确认信号与价位（如"回踩 X 价不破并放量下行后确认"） |
| ❌ 不通过 | 处于上升趋势、宽幅震荡，或仅为下跌后的超卖反弹/反抽 → 结论锁定"放弃（趋势不支持）" |
