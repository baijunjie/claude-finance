# 逼空/反弹风险、Pre-mortem 与退出计划（Filter 4 + 第 6 步）

"反过来想"——做空前先穷尽这笔交易**如何被打爆、如何亏光权利金**。这是 1-2 个月期权窗口里最现实的杀手：方向可能对，但被一波逼空或反弹震出场、或被 theta 拖死。

## 目录

1. 逼空风险核查（短期最致命）
2. 短期反弹/反转风险
3. 拥挤交易风险
4. F4 风险清单（任一严重 → 否决/降级）
5. F4 评分锚点
6. Pre-mortem 操作方法
7. 退出计划（止盈 / 止损 / 时间止损）

## 1. 逼空风险核查（short squeeze）

买 put 虽然最大亏损锁定为权利金，但一波逼空足以在到期前把 put 打到归零。逐项核查：

| 指标 | 危险信号 | 说明 |
|------|---------|------|
| 做空比例（SI % of float） | > 15-20% 🚨 | 空头越拥挤，逼空燃料越足 |
| Days to cover（回补天数） | > 5 天 🚨 | 空头需多日才能买回，利好时踩踏 |
| 融券成本 / borrow fee | 飙升或 > 数十% 年化 🚨 | 高 borrow 说明券源紧、逼空概率高 |
| 流通盘 / 自由流通股 | 极小 🚨 | 小盘股易被资金拉动 |
| 散户抱团 / meme 属性 | 社媒热度高 🚨 | 非理性买盘，逼空与基本面脱钩 |
| Gamma squeeze 结构 | 大量近月 call 未平仓 🚨 | 做市商对冲会助推上涨 |

**逼空正在进行**（borrow 飙升 + 股价逆势急拉 + 社媒热度暴涨）→ F4 直接否决，无论 F1/F2 多漂亮。

## 2. 短期反弹/反转风险

呼应趋势层第 5 节的短期反转效应（1 个月内）。核查标的当前是否处于**易反弹位置**：
- RSI 极低（如 < 30）、连续多根大阴线后、跌速过快（乖离率过大）
- 临近强支撑（前期平台、整数关口、长期均线）
- 已跌至 52 周低点且出现恐慌放量（可能阶段性底）

若当前正是超卖反弹高发点 → 不立即做空，等反弹乏力、趋势重新确认后再入场（归入 F1 的"有条件通过"或 F5 的入场时机）。

## 3. 拥挤交易风险

- 是否人人都已看空（卖方一致下调、空头比例创新高、媒体一边倒看衰）？拥挤的空头一遇边际利好或超预期，回补踩踏放大反弹。
- 是否有强力买盘对冲：大股东/公司回购、产业资本举牌、并购传闻、政策托底。
- 反向情绪信号：极端看空往往对应短期超卖，需与 F1 趋势强度权衡。

## 4. F4 风险清单（在备忘录中固定逐条判定）

| 风险 | 判定 |
|------|------|
| 逼空（高 SI / 高 days-to-cover / 高 borrow） | 🚨 严重 / ⚠️ 中等 / ✅ 低 |
| 散户抱团 / meme 属性 | |
| Gamma squeeze 结构 | |
| 短期超卖反弹 | |
| 强力买盘（回购/举牌/并购/政策） | |
| 空头拥挤（一致看空） | |

任一标"严重"→ 否决或降级为观察。

## 5. F4 评分锚点（0-10，**越高越安全**）

| 分数 | 标准 |
|------|------|
| 8-10 | 做空比例低、borrow 正常、流通盘大、非 meme、当前非超卖、无强力买盘 |
| 5-7 | 个别风险中等（如 SI 偏高但 days-to-cover 不大），可控但需在退出计划中防范 |
| 3-4 | 多项风险偏高，或当前明显超卖——降级为观察，等更好入场点 |
| 0-2 | 逼空正在进行 / 强 meme 属性 / 极度超卖 → 否决 |

## 6. Pre-mortem 操作方法

假设：**期权到期日，这笔做空亏光了全部权利金。写一篇"事后复盘"解释为什么。**

要求：
- 写出 3-5 条最可能的失败路径，按概率排序
- 每条给出估算概率区间（期权到期前发生的主观概率，如 25%–35%）：概率须与排序一致；用宽区间表达不确定性，不写伪精确单点数字
- 每条注明：当前是否已有早期信号？什么信号出现时应当平仓？
- 失败路径必须具体到机制，常见六类：
  1. **趋势反转**：跌破后快速收复关键均线/颈线，下降趋势证伪
  2. **逼空**：空头回补/gamma 踩踏式拉升
  3. **IV crush**：催化剂（尤其财报）落地后 IV 崩塌，方向对但 put 仍亏（见 option-structure.md）
  4. **催化剂落空/反向**：预期的利空未兑现，或出现超预期利好（回购、并购、政策、订单）
  5. **theta 拖死**：方向对但下跌太慢，时间价值衰减跑赢跌幅
  6. **超卖反弹**：短期反转效应，未到目标位先被震出

## 7. 退出计划（对应"不持有到期、找点位平仓"）

每次做空必须预先写定三条线，落到具体价位/比例，禁止"看情况"：

- **止盈**：标的跌至目标位即平仓——目标位取下方强支撑、前期低点、或跌幅达预期波动的 X%（如达预期波动的 70-80% 即兑现，不贪到期）。可分批止盈。
- **止损**：标的反向突破关键阻力（如放量重回 50 日均线上方、收复颈线）→ 下降趋势证伪，认赔离场；或权利金回撤达预设比例（如 −50%）强制止损。
- **时间止损**：到期前 ~21 天若论点仍未兑现，平仓离场——避开 theta 加速衰减区，把残值收回。

退出计划须写进备忘录第七节，并与 F5 选定的到期日/行权价一致。
