# 期权结构与赔率（Filter 5）

Filter 5 把前四层的判断翻译成一句话：**这笔看跌期权到底划不划算？** 做**定性 + 关键指标**评估，不做精确 Black-Scholes 定价（"宁要模糊的正确，不要精确的错误"）。核心矛盾：方向对、时间对，但若 IV 太贵或预期波动已覆盖目标跌幅，照样不赚钱。

## 目录

1. IV 水平：put 贵不贵
2. IV crush 陷阱（尤其财报）
3. 预期波动 vs 你的目标跌幅
4. Theta 与到期日选择
5. 行权价与盈亏平衡
6. 风险回报比
7. F5 判定锚点

## 1. IV 水平：put 贵不贵

- **IV Rank**：`(当前 IV − 过去一年最低 IV) / (过去一年最高 IV − 过去一年最低 IV)`，0-100%。
- **IV Percentile**：过去一年中 IV 低于当前值的交易日占比。
- 判定：
  - IV Rank **低**（如 < 30）✅：put 相对便宜，买方有利。
  - IV Rank **高**（如 > 60）🚨：put 贵，且大概率面临均值回归式的 IV 回落（vega 亏损），即使方向对也吃力。
- 对比 **HV（历史波动率）**：IV 远高于 HV，说明市场已对大波动定价，你为"已知的恐慌"付了溢价。

## 2. IV crush 陷阱（尤其财报）

- 财报/重大事件**前** IV 显著抬升，**后**无论股价往哪走，IV 急剧回落（crush）。
- 临近财报买 put：若财报后股价小跌甚至不跌，IV crush 会让 put 大幅贬值——**方向对也亏钱**。
- 规则：
  - 若催化剂 = 财报，**避免在财报前一两天追高 IV 买 put**；优先在财报前 IV 尚低时布局，或等财报后 IV 回落、趋势延续再做。
  - 在备忘录中明确标注目标期权是否跨越财报日，以及对应的 IV crush 敞口 🚨。

## 3. 预期波动 vs 你的目标跌幅

用隐含波动估算到期前的"市场预期波动幅度"：

```
预期波动（1 个标准差，到期前）≈ 股价 × IV × √(DTE / 365)
```

- 若你预期的下跌幅度**已经落在**市场预期波动范围内 → 这个跌幅已被 put 价格涵盖，赔率平庸 ⚠️。
- 真正有利的做空：你预期的跌幅（基于趋势目标位 + 戴维斯双杀测算）**显著超过**市场隐含的预期波动 ✅。
- 把目标跌幅、预期波动、盈亏平衡跌幅三者并列对比。

## 4. Theta 与到期日选择

- Theta（时间价值衰减）在到期前最后 ~30 天**加速**，越临近到期、ATM 期权衰减越快。
- 1-2 个月窗口的建议：
  - **买 ~45-60 DTE**（到期日），给趋势/催化剂留出兑现时间，又不必付过长的时间价值；
  - **在最后 ~21 天 theta 加速前平仓**（呼应退出计划的时间止损）；
  - 不做空 < 30 DTE 的短期 put（theta 太凶、容错太低，用户已明确 1 个月内风险过高）。

## 5. 行权价与盈亏平衡

- **行权价选择**：
  - ATM（平值）：delta ≈ −0.5，对标的下跌反应灵敏，权利金较高；
  - 略 OTM（虚值）：权利金低、杠杆高，但需要更大跌幅才进入实值，对 theta 更敏感；
  - 深 OTM：除非预期暴跌或博催化剂，否则胜率低。
- **盈亏平衡价（长 put）**：`行权价 − 权利金`。判断：到期前标的能否合理跌破盈亏平衡价？盈亏平衡跌幅与第 3 节预期波动比较。

## 6. 风险回报比

- **最大亏损 = 权利金**（买方风险锁定，这是相对裸卖空的核心优势）。
- 按目标位估算回报：`(目标价位下的 put 内在价值 − 权利金) / 权利金`，得到回报/风险倍数。
- 结合 Pre-mortem 的失败概率，做粗略期望值判断：高 IV 买贵的 put + 平庸目标跌幅 = 负期望，再正确的方向也该放过。

## 7. F5 判定锚点

| 判定 | 标准 |
|------|------|
| ✅ 划算 | IV Rank 偏低（put 不贵）+ 目标跌幅显著超过预期波动 + 无临近财报 IV crush 敞口 + 风险回报比 ≥ 2:1 + 到期日 45-60 DTE |
| ⚠️ 勉强 | 单项不利（如 IV 中性偏高，或目标跌幅仅略超预期波动，或跨财报需防 crush），需更严格的入场点与退出纪律 |
| 🚨 不划算 | IV Rank 高（贵且易 crush）/ 预期波动已覆盖目标跌幅 / 风险回报比 < 1.5:1 / 被迫买临近财报的高 IV put → 降级为"观察（等期权时机）" |

**降级 ≠ 放弃**：F1+F2 论点成立但 F5 不划算时，结论为"观察"——等 IV 回落、或等更好的入场价位再买 put，而非否定做空逻辑本身。
