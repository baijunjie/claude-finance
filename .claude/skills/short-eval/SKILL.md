# 做空适配度评估（Short Eval）

用一套可证伪的标准评估一只股票是否适合**买入看跌期权做空**：**顺着已确认的下降趋势、做空已确认的坏公司，在 1-2 个月窗口内找点位平仓。** 评估的目的不是找到"它会跌"的理由，而是穷尽"这笔做空会亏钱"的理由——双必要条件全过、且期权赔率划算才值得出手。

## 核心范式：右侧交易，不抓拐点

本模型**不预测顶部、不抓拐点**（那是左侧交易，在 1-2 个月期权窗口里风险过高、无法证伪）。它只在**趋势已经确认向下**时，顺着已经发生的弱势做空。做空者最经典的死法是"方向对、死在太早"——本模型用"已确认的下降趋势"替代"预测的拐点"，把最难的"时间正确"从预测变成确认。

**因此两个必要条件缺一不可：**
- 只跌不坏（趋势向下但基本面没问题）→ 可能是错杀，随时反弹，**不做**。
- 只坏不跌（基本面很差但仍在上升趋势）→ 经典的"太早"，泡沫能持续数年，**不做**。

**宏观层（F0）的左侧例外**：不抓个股拐点，但允许**带护栏的左侧宏观判断**——宏观可作为顺风/逆风确认，也可作为论点驱动与催化剂（risk-off / 紧缩 = 做空顺风）。但有铁律：**宏观单独不能覆盖 F1，个股趋势仍是硬必要条件**（宏观+趋势共振才行）。同时，宏观也可能**终结一个已确认的下降趋势**（如鸽派转向引爆普涨），这一风险须进 F0 与 Pre-mortem。

## 评估原则

- **逆向优先**：先问"什么会让这笔做空亏钱"（逼空、反弹、IV crush、theta 衰减、趋势反转），再问"它为什么会跌"。
- **否决制，非加权平均**：任一必要条件不及格即整体否决，高分项不能弥补低分项。做空的下行风险（买 put 虽锁定最大亏损为权利金，但时间一到归零）要求排除法，不是凑总分。
- **证据驱动**：每个结论必须有具体证据（价格结构、财务数据、空头数据、期权链报价），禁止用形容词代替证据。"走势很弱"不是证据，"连续 3 个月更低的高点和更低的低点、价在 200 日均线下方 18%"才是。
- **theta 是敌人**：1-2 个月的 put 每天都在流血。没有趋势延续或催化剂支撑的"慢慢阴跌"会被时间价值吃掉——宁可放过，不可硬扛。
- **承认不确定**："趋势不明 / 数据不足，放弃"是合法且体面的结论，比强行做空更有价值。

## 工作流程

### 第 0 步：数据收集

评估开始前，收集以下数据（来源优先级：用户提供的材料 > 联网搜索行情/财报/期权数据 > 模型已有知识，并注明数据截止时间）：

- **宏观环境（F0 用）**：大盘指数趋势与宽度、利率/央行政策与流动性、收益率曲线、信用利差（HY OAS）、VIX 制度、美元与大宗、板块/风格轮动；窗口内宏观日历（FOMC、CPI/PCE、NFP、央行会议等）；标的与大盘的相关性/beta
- **价格与趋势**：近 12 个月日线走势、52 周高/低点、相对 50/200 日均线位置、近 3/6 个月相对大盘与所属板块的相对强弱、成交量结构
- **基本面（坏公司判定用）**：近 5 年营收/毛利率/经营利润率/净利润趋势、经营现金流 vs 净利润、应收/存货 vs 营收增速、有息负债与到期结构、利息保障倍数、自由现金流；用于计算 Altman Z / Beneish M / Piotroski F / Sloan 应计的明细科目
- **估值**：P/E、P/S、EV/EBIT、EV/Sales 及其相对历史与同行分位
- **催化剂日历**：未来 1-2 个月的财报日、指引、解禁、债务到期、评级、监管/诉讼节点
- **空头与拥挤度**：做空比例（short interest % of float）、days to cover、融券成本/borrow fee、近期空头变化、是否散户抱团/meme 标的
- **期权链**：目标到期月各行权价的报价、隐含波动率（IV）、IV rank/percentile、历史波动率（HV）、各 greeks（尤其 theta、delta、vega）

数据不足时明确标注"数据缺口 ❓"，不要编造。期权与空头数据缺失会直接削弱 F4/F5 的可靠性，须显著标注。

### 第 0.5 步：宏观环境过滤器（Filter 0，在 F1 之前执行）

读取 [references/macro-regime.md](references/macro-regime.md)，自上而下先判宏观大势，承担三个角色：

- **顺风/逆风确认**：判断宏观制度是否支持做空方向——risk-off / 紧缩 / 信用利差走阔 / VIX 抬升 = ✅ 顺风；risk-on 普涨 / 宽松放水 = 🚨 逆风。**强逆风（明确反向 + 个股高 beta）→ 否决或降级**，哪怕个股再弱。
- **左侧宏观引擎（可选，带护栏）**：允许把宏观拐点作为论点驱动与催化剂（喂给 F3），但必须锚定到窗口内带截止日的触发 + 跨资产确认 + 减仓/更长 DTE；且**个股 F1 趋势仍须至少初步确认——宏观单独不能覆盖 F1 否决**。
- **趋势终结风险**：评估窗口内是否有宏观事件可能**终结当前下降趋势**（央行鸽派、政策刺激、空头回补共振），喂给第 6 步 Pre-mortem。

判定三档：**✅ 顺风 / ⚠️ 中性 / 🚨 逆风**。中性时 F0 不加不减，按 F1-F5 推进。

### 第 1 步：趋势确认过滤器（Filter 1，必要条件）

读取 [references/trend-confirmation.md](references/trend-confirmation.md)，按其中标准判定标的是否处于**确认的中期下降趋势**：

- 道氏理论结构：是否形成连续更低的高点 + 更低的低点？
- 均线与位置：价是否在 200 日均线下方、且 50 日在 200 日下方（空头排列）？
- 相对强弱 / 动量：近 3-6 个月是否持续跑输大盘与板块？（动量/趋势跟踪的形成窗口看中期，不是"上个月跌了"）
- 反弹风险预判：当前是否处于超卖反弹或下降趋势中的反抽？（短期反转效应，详见 F4）

判定分三档：**通过 / 有条件通过 / 不通过**。"有条件通过"用于趋势刚转弱、结构未完全确认（如刚跌破颈线但尚未回踩确认）的情形，必须写明要求确认的具体信号与价位。

**F1 不通过（处于上升趋势或宽幅震荡）→ 最终结论锁定为"放弃（趋势不支持）"**，并在结论速览中写明 F1 是首要否决项；但其余各层照常完成作为证据链——若日后趋势转空，备忘录可复用。**哪怕基本面再差、估值泡沫再大，上升趋势中一律不做空。**

### 第 2 步：坏公司基本面过滤器（Filter 2，必要条件）

读取 [references/bad-company-redflags.md](references/bad-company-redflags.md)，按其中的量化模型与红旗清单逐项检验，判定标的是否真的是"坏公司"：

- **困境与质量**：Altman Z-Score（破产距离）、Piotroski F-Score（财务健康度，做空看低分）、质量因子（盈利、成长、安全、稳定的反面）
- **财务造假/盈余操纵红旗**：Beneish M-Score、Sloan 应计利润、经营现金流与净利润背离、应收/存货异常
- **结构性恶化**：商业模式终局、行业结构性衰退、毛利率/份额持续流失、戴维斯双杀的双引擎（盈利下修 × 估值压缩）是否在途
- **估值的角色**：高估值**只是放大器，不是做空理由**（高估能持续数年）；只有当趋势(F1)已经在压估值时，高估值才转化为下行空间

### 第 3 步：催化剂过滤器（Filter 3，加速器，非必要）

判定 1-2 个月窗口内是否有可**加速既有下跌**的事件——注意这里催化剂的角色不是"引爆拐点"，而是"在 theta 吃掉权利金之前提高兑现概率"：

- 候选催化剂：财报/指引下修、债务到期或再融资、限售解禁、评级下调、监管/诉讼裁决、行业数据节点、同业暴雷的传染
- 对每个催化剂判定：时间是否落在期权到期日**之前**？方向是否明确利空？市场是否已充分定价（已 priced in 的催化剂不加分）？
- **没有催化剂不否决**：若 F1+F2 双确认强，可纯靠趋势延续做空，但须在 F5 中相应调低赔率预期、并缩短持有计划。
- **催化剂 = 财报时要特别警惕 IV crush**（见 F5）：财报前 IV 抬升，财报后无论方向如何 IV 崩塌，临近财报买 put 常是陷阱。

### 第 4 步：逼空 / 反弹风险过滤器（Filter 4，逆向层）

读取 [references/squeeze-risk.md](references/squeeze-risk.md)，排查"做空者如何被打爆"——这是 1-2 个月窗口里最现实的杀手：

- **逼空风险**：做空比例过高、days to cover 过大、borrow fee 飙升、流通盘小、散户抱团/meme 标的、是否有 gamma squeeze 结构
- **短期反转/反弹风险**：学术上 1 个月内存在短期反转效应——当前是否已严重超卖（RSI 极低、连续大阴线后），随时技术性反弹？
- **拥挤交易**：是否所有人都在做空（拥挤的空头一有利好就踩踏式回补）？
- 评分越高越安全；触发严重逼空风险（如逼空正在进行）→ 直接否决或降级。

### 第 5 步：期权结构与赔率过滤器（Filter 5，把判断翻译成"这笔 put 划不划算"）

读取 [references/option-structure.md](references/option-structure.md)，做**定性 + 关键指标**评估（不做精确 Black-Scholes 定价）：

- **IV 水平**：IV rank / percentile 是否过高？（高 IV = put 贵 + 易遭 IV crush）；IV vs HV 的关系
- **预期波动 vs 隐含波动**：用预期波动 ≈ 股价 × IV × √(DTE/365) 估算到期前的隐含波动幅度，对比你预期的下跌幅度——隐含波动已涵盖你的目标跌幅时，赔率不佳
- **Theta 与到期日选择**：1-2 个月窗口建议买 ~45-60 DTE、在最后 ~21 天 theta 加速前平仓；行权价（ATM/略 OTM）与盈亏平衡点
- **风险回报比**：最大亏损 = 权利金；按目标下跌点位估算回报/权利金倍数；盈亏平衡价是否在合理可达范围内
- 赔率不划算（IV 太贵、预期波动已覆盖目标跌幅、风险回报比过低）→ 结论降级为"观察（等期权时机）"。

### 第 6 步：逆向 Pre-mortem 与退出计划

读取 [references/squeeze-risk.md](references/squeeze-risk.md) 的 Pre-mortem 与退出计划部分，执行：

1. **Pre-mortem**：假设期权到期时这笔做空亏光权利金，写出 3-5 条最可能的原因（趋势反转、**宏观逆转终结下降趋势（F0 识别的宏观事件，如央行鸽派/政策刺激引爆普涨）**、被逼空、IV crush、催化剂落空/利好、theta 衰减跑赢跌幅），按概率排序，每条给出**估算概率区间**并满足：① 概率与排序一致；② 用宽区间表达不确定性；③ 与各层风险判定口径（含 F0）互相校验。
2. **退出计划**（对应"不持有到期、找点位平仓"）：必须明确写出
   - **止盈**：目标价位/标的跌幅 → 平仓点（如标的跌至支撑位、跌幅达预期波动的 X%）
   - **止损**：标的反向突破关键阻力（如重回 50 日均线上方）或权利金回撤达 X% 时认赔
   - **时间止损**：到期前 ~21 天若论点未兑现则离场（避开 theta 加速）

### 第 7 步：输出评分卡 + 做空备忘录

按 [assets/memo-template.md](assets/memo-template.md) 模板生成备忘录，保存到当前工作目录 `output/short-eval/<标的名>-<日期>.md`（目录不存在时先创建）。

**判定标识（全文统一使用，提高辨识度）：**

| Emoji | 含义 | 用在哪里 |
|-------|------|---------|
| ✅ | 确认有利做空 / 确认通过（证据充分的正面判定） | 趋势确认向下、坏公司成立、催化剂存在且利空、逼空风险低、赔率划算 |
| 🚨 | 确认不利 / 否决项（证据充分的负面判定） | 上升趋势、逼空正在进行、IV crush 陷阱、触发否决/降级的分项 |
| ⚠️ | 存疑（证据不足或方向不明，结论可被新证据翻转） | 趋势刚转弱、坏公司证据不足、有条件通过 |
| ❓ | 数据缺口（数据不全、待核实，影响判定可靠性） | 引用估算值/未核实数据处、第九节数据缺口列表（期权/空头数据缺失常见） |
| ❌ | 不通过 / 无（明确的"没有"） | 趋势不向下、非坏公司、无催化剂、赔率不成立 |

使用规则：结论速览表、坏公司红旗表、逼空风险清单的判定列**必须**带标识；正文中的关键判定（趋势结构、Z/M/F 分数、IV rank、风险回报比）在判定词后紧跟标识；不要在叙述性文字中滥用，每个标识只标判定本身。

**评分与结论规则（否决制，F1∩F2 为双必要条件）：**

| 过滤器 | 评分 | 及格线 |
|--------|------|--------|
| F0 宏观环境 | 顺风 / 中性 / 逆风 | **强逆风（明确反向 + 高 beta）→ 否决或降级**；中性不加不减；左侧引擎不可单独覆盖 F1 |
| F1 趋势确认 | 通过 / 有条件通过 / 不通过 | **不通过（非下降趋势）→ 结论锁定"放弃（趋势不支持）"** |
| F2 坏公司基本面 | 0-10 | < 6 → 否决（"只跌不坏"不做） |
| F3 催化剂 | 0-10（加速器） | 不设否决线；0 分仅表示"靠趋势延续，赔率与持有计划相应打折" |
| F4 逼空/反弹风险（越高越安全） | 0-10 | < 5 → 降级为"观察"；逼空正在进行 → 否决 |
| F5 期权赔率 | 划算 / 勉强 / 不划算 | 不划算 → 降级为"观察（等期权时机）" |

- F0 非强逆风 + F1 通过（或有条件通过且确认） + F2 ≥ 7 + F4 ≥ 6 + F5 划算（宏观顺风/有催化剂更佳）：**做空**（值得建仓买 put）
- 论点成立（F1+F2 过）但 F0 逆风 / F4 偏高风险 / F5 赔率不划算（如 IV 太贵）：**观察**（等宏观转向、更好入场点或期权时机）
- F0 强逆风 / F1 不通过 / F2 < 6 / F4 逼空进行中：**放弃**，写明单一否决原因
- 注意区分用词：F0 强逆风/F1/F2/F4 不及格是"**否决**"，F0 逆风、F4 中等风险与 F5 不划算是"**降级**"，结论速览表中统一填入"否决/降级原因"一行
- 评分必须附证据引用；没有证据支撑的分项最高给 5 分
- F2/F4 每层末尾必须附"**评分依据**"，对照各 reference 的评分锚点说明为何给该分

## 注意事项

- 这是**短期（1-2 个月）、买入看跌期权、不持有到期、找点位平仓**的做空适配度框架，不适用于：裸卖空/融券长期持有、价值投资做多、套利、不设期限的趋势空头、财报当天的事件博弈
- 如果用户一次给出多只标的，逐只独立评估后再给比较表，不要在单只评估中互相参照妥协
- 严格按模板的章节标题与固定格式输出（含第二节的宏观环境、第七节的逼空风险清单表格、第八节的 Pre-mortem 与退出计划、第十节的复核触发条件、第十一节的数据来源汇总），不要增删或改写章节标题
- 期权报价、IV 与空头数据时效性极强，正文引用处必须标注数据时间；缺失时标 ❓ 并说明对赔率判定的影响
