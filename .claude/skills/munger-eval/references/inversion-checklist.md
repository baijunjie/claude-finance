# 逆向思维与心理误判排查清单

第 5 步使用。"反过来想，总是反过来想"——不问这笔投资为什么会成功，先穷尽它失败的方式。

## 目录

1. Pre-mortem 操作方法
2. 毁灭性风险清单（任一成立可单独否决）
3. 财务欺诈红旗
4. 心理误判自查清单（检查本次分析自身）

## 1. Pre-mortem 操作方法

假设：**现在是 10 年后，这笔投资亏损了 50%。写一篇"事后复盘"解释为什么。**

要求：
- 写出 3-5 条最可能的失败路径，按概率排序
- 每条给出估算概率区间（10 年内发生的主观概率，如 20%–30%）：概率须与排序一致；用宽区间表达不确定性，不写伪精确的单点数字
- 每条注明：当前是否已有早期信号？什么指标恶化时应当卖出？
- 失败路径必须具体到机制（"竞争加剧"不合格；"X 技术使单位成本降到本公司的一半，2-3 年内侵蚀高端市场"合格）

## 2. 毁灭性风险清单

逐条核对，标注"存在 / 不存在 / 存疑"。任何一条明确存在，无论其他评分多高，结论直接降为"放弃"或"观察"：

| # | 风险 | 核对要点 |
|---|------|---------|
| 1 | 致命杠杆 | 净有息负债/EBITDA > 3 倍；短债长投；衍生品敞口不透明。"聪明人破产的三个原因：酒（liquor）、女人（ladies）和杠杆（leverage）" |
| 2 | 技术颠覆在途 | 替代技术已商业化且成本曲线快速下降（即使现在还不如现有方案） |
| 3 | 单一依赖 | 单一客户/供应商/产品/牌照占收入或利润 > 30%，且对方议价地位更强 |
| 4 | 监管/政治风险 | 商业模式依赖监管套利；利润高到引发"社会容忍度"问题；地缘政治敞口 |
| 5 | 股权结构陷阱 | 大股东与小股东利益冲突史（关联交易、低价私有化、占款） |
| 6 | 行业产能竞赛 | 全行业都在加资本开支，回报必然均值回归（"好行业坏时点"） |
| 7 | 商业模式合法性边缘 | 增长依赖灰色地带，一纸文件可摧毁 |

## 3. 财务欺诈红旗

任意 2 条以上同时出现 → F3 管理层评分上限 3 分，并在备忘录显著位置警示：

- 净利润持续高增长但经营现金流长期跟不上（CFO/净利润 < 70% 连续 3 年）
- 应收账款/存货增速持续显著高于营收增速
- 毛利率显著高于同行却无可解释的结构性原因
- 频繁更换审计师，或审计费异常低
- 大存大贷：账上巨额现金同时维持高额有息负债
- 复杂的关联交易网络、频繁的资产重组
- 管理层/大股东高位密集减持，或股权质押比例高
- 激进的收入确认政策（总额法/完工百分比滥用）

## 4. 心理误判自查清单

完成分析后，回头检查**本次分析自身**是否中招。摘自《人类误判心理学》中与投资分析最相关的偏误：

| 偏误 | 自查问题 |
|------|---------|
| 确认偏误 / 第一结论偏误 | 是否先有了"想买"的结论再去找证据？反方证据找得和正方一样努力吗？ |
| 社会认同 | 评分是否被"知名投资人也持有"、"市场共识看好"抬高了？ |
| 近因效应 / 可得性 | 是否过度外推了最近 1-2 年的业绩？10 年前的数据看了吗？ |
| 喜爱/讨厌倾向 | 是否因为喜欢这家公司的产品/创始人故事而放松了标准？ |
| 权威误导 | 是否因为管理层口才好、年报写得漂亮而给了高分？ |
| 激励引起的偏见 | 信息来源（券商研报、公司 IR 材料）的利益立场是什么？ |
| 被剥夺超级反应（损失厌恶） | 如果已持有该股票，是否在为"不卖"找理由？ |
| 一致性/承诺倾向 | 是否因为之前公开看好过，这次不愿推翻自己？ |
| 过度乐观 | 情景测算中"悲观情形"够悲观吗？是不是只是"不那么乐观"？ |

自查发现中招的，回到对应步骤修正评分，并在备忘录"分析自查"一节记录修正过程。
