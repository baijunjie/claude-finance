# 颠覆与依赖风险 · Pre-mortem · 分析自查

F5 与第 7 步使用。"反过来想，总是反过来想"——不问这笔投资为什么会成功，先穷尽科技公司特有的死法。

## 目录

1. Pre-mortem 操作方法
2. 毁灭性风险清单（否决项）
3. 科技版红旗（叙事与会计）
4. 心理误判自查清单（检查本次分析自身）

## 1. Pre-mortem 操作方法

假设：**现在是 10 年后，这笔投资亏损了 50%。写一篇"事后复盘"解释为什么。**

要求：

- 写出 3–5 条最可能的失败路径，按概率排序
- 每条给出估算概率区间（10 年内发生的主观概率，如 20%–30%）：概率须与排序一致；用宽区间表达不确定性，不写伪精确的单点数字
- 每条注明：当前是否已有早期信号？什么指标恶化时应当卖出？
- 失败路径必须具体到机制。"竞争加剧"不合格；"通用模型把该产品的核心工作流变成对话框里的一个功能，客户从付费席位转为只保留系统记录，NRR 从 118% 降到 95% 以下"合格
- **科技公司的失败路径往往不是"业绩崩塌"而是"增速正常化 + 倍数收缩"**。至少有一条路径要写这种情形：业绩符合预期但估值倍数腰斩
- 若 F5 有"⚠️ 存疑"项，该项必须出现在头部路径中

## 2. 毁灭性风险清单

逐条核对，标注"存在 / 不存在 / 存疑"。任何一条明确**存在且不可逆**，无论其他评分多高，结论直接降为"放弃"。

| # | 风险 | 核对要点 |
|---|------|---------|
| 1 | 技术代际颠覆在途 | 新范式已商业化且成本/能力曲线快速改善；公司的权力附着在旧代际的资产上（见 F1 代际归属）。判断依据不是"新技术现在还不如它"，而是"改善速度" |
| 2 | 通用模型吃掉需求 | 产品的核心价值是否可被通用模型直接完成？客户能否用模型 + 少量工程自建？反向判断：产品若是**系统记录与工作流治权**，模型是增强而非替代 |
| 3 | 开源商品化 | 核心技术是否存在开源等价物且质量在追平？付费理由若只剩"托管与服务"，毛利率与定价权会持续下行 |
| 4 | 平台寄生 | 收入/流量高度依赖单一平台（应用商店、搜索流量、社交分发、某云、某模型 API）。平台可改规则、抽税、自营同类产品。查历史上平台是否已做过一次 |
| 5 | 单一依赖 | 单一客户/供应商/产品/合约占收入或利润 > 30%，且对方议价地位更强；或大客户本身就是潜在竞争者（既买又自研） |
| 6 | 监管与法律 | 反垄断（拆分、默认位禁令）、隐私与定向广告、版权与训练数据、跨境数据与出口管制、内容责任、平台劳动关系。判断"一纸文件能不能改掉商业模式" |
| 7 | 治理陷阱 | 双层股权下小股东无救济；关联交易与循环交易；无限增发授权；SPAC/重组遗留结构；创始人失控或离场风险 |
| 8 | 资金链断裂 | 未盈利公司：现金跑道 < 24 个月且需要持续外部融资；可转债到期墙；资本市场关闭时无退路 |
| 9 | 稀释失控 | SBC 长期超过真实自由现金流，稀释后股本持续净增，股东回报被员工薪酬吸收。持续多年且管理层无收敛计划 → 按"存在"处理；未达此程度的稀释问题在 F3/F4 扣分，不在本层否决 |

判定纪律：

- "存疑"用于风险在途但结果未定（如开源方案正在追赶但尚未追平）。存疑项**至多"观察"**，且必须进入 Pre-mortem 头部路径
- 区分**可逆与不可逆**。平台抽税可能被谈判回来（可逆），客户完成自研迁移通常不可逆
- 每条判定"存在/存疑"的，在判定列展开一句话说明依据

## 3. 科技版红旗（叙事与会计）

任意 2 条以上同时出现 → F4 评分上限 3 分，并在备忘录显著位置警示：

- **"调整后"才盈利**：剔除 SBC 后才有正利润，却以"已盈利"对外宣称
- **关键指标改口径或停止披露**：DAU、NRR、客户数、ARR 定义变更或不再公布（停止披露几乎总是坏消息）
- **递延收入/RPO 增速显著低于收入增速**：收入前置或新签走弱
- **循环交易与关联方**：客户同时是投资方；供应商入股客户后客户用融资款采购；关联方之间的巨额算力/许可承诺
- **RPO 或收入高度集中于一两个超大单**，且交易对手财务能力可疑
- **用股权支付的频繁并购冲增速**，且不披露被并购业务的单独表现
- **重组费用常态化**：连续多年"一次性"费用
- **TAM 反复上调而份额无验证**：故事越讲越大，市占率却讲不清
- **资本化率或折旧年限的口径变更**恰好发生在利润承压时
- **CFO / 审计师 / 核心技术高管密集离职**
- **管理层在高位密集减持**，或回购恰好集中在股价高点（对冲稀释而非创造价值）

## 4. 心理误判自查清单

完成分析后，回头检查**本次分析自身**是否中招。科技股尤其容易踩以下几条：

| 偏误 | 自查问题 |
|------|---------|
| 叙事偏误 | 结论是被一个精彩的故事（"AI 时代的水电煤"、"下一个平台"）驱动的，还是被证据驱动的？把故事删掉，剩下的证据还支持这个评分吗？ |
| TAM 幻觉 | 是否接受了公司自报的 TAM？自己独立算过可服务市场与合理份额上限吗？隐含营收对应的份额说得出口吗？ |
| 增长外推 | 是否把当前增速线性外推？同原型公司到这个营收规模时增速通常掉到多少（基础比率）？ |
| 技术崇拜 | 是否因为技术方案精妙、架构优雅而给了高分？技术优势有没有转成 Barrier？ |
| 确认偏误 / 第一结论偏误 | 是否先有了"想买"的结论再找证据？反方证据找得和正方一样努力吗？第 7 步的空头论点是认真构造的还是稻草人？ |
| 社会认同 / FOMO | 评分是否被"知名投资人重仓"、"社交媒体共识"、"错过了会后悔"抬高了？ |
| 权威误导 | 是否因为创始人口才好、股东信写得漂亮、投资者日 PPT 精美而给了高分？ |
| 近因效应 | 是否过度外推了最近 1–2 个季度（尤其是刚发布新产品后的一个季度）？看了完整的周期吗？ |
| 锚定 | 是否在用"比历史高点跌了 X%"当便宜的理由？倍数收缩后的价格与内在价值无关 |
| 激励引起的偏见 | 信息来源（券商研报、公司 IR、行业顾问、KOL）的利益立场是什么？ |
| 一致性/承诺倾向 | 是否因为之前公开看好过或已持有，这次不愿推翻自己？ |
| 过度乐观 | 悲观情形够悲观吗？里面有没有倍数收缩？还是只是"不那么乐观"？ |

自查发现中招的，回到对应步骤修正评分，并在备忘录"反方压力测试与分析自查"一节记录修正过程（修正前后的评分变化）。
