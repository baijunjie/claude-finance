# 增长质量与科技公司单位经济学

F3 的详细检验标准。这一层的任务是**戳穿 GAAP 与"调整后"口径的失真**，回答两个问题：扣掉所有真实成本后这门生意赚钱吗？增长是买来的还是长出来的？

## 目录

1. 口径校正：把失真拆掉

## 1. 口径校正：把失真拆掉

### 1.1 股权激励（SBC）——最大的单一失真源

- **SBC 是真实成本**，不是"非现金费用"。它的经济实质是：公司用股东的所有权支付了员工薪酬
- 处理方法（二者取一，写明用了哪个）：
  - **稀释法**：所有每股指标一律用**完全稀释后股本**，并把股本的历年净增速单列
  - **回购法**：真实 FCF = 报表 FCF − 为抵消稀释所需的回购额（用实际回购额近似，若回购不足则用 SBC 全额）
- 🚨 红旗：公司的"调整后 EBITDA / 调整后净利润 / 调整后毛利率"在剔除 SBC 后才转正。此时以调整后口径宣称"已盈利"应直接视为误导性披露，计入 F4
- 交叉验证：SBC 占营收比与同原型同规模公司对比；> 20% 属于高，> 30% 属于失控（结合 §3 门槛表）

### 1.2 资本化研发与云基础设施

- 软件开发成本资本化率的**变化**是常见的利润调节手段：资本化率上升 → 当期费用变少、利润变好、经营现金流不变但 FCF 变差
- 检验：资本化开发成本 / 总研发支出的历年趋势；若上升，把差额还原成费用后重算利润率
- 自建数据中心 vs 租用云：自建把成本移入资本开支与折旧，报表毛利率更好但 FCF 更差。**跨公司比毛利率前先统一口径**
- 折旧年限假设：服务器/GPU 的折旧年限被拉长会系统性高估利润。做敏感性测试（年限缩短 1–2 年对利润与 FCF 的影响），AI 基础设施类必做

### 1.3 递延收入与 RPO（订阅公司专用）

- 当期收入是过去销售的确认结果，**领先指标是 RPO / cRPO（12 个月内将确认的剩余履约义务）与净新增 ARR**
- 检验：递延收入与 RPO 的增速 vs 收入增速。递延收入增速显著低于收入增速 → 🚨 收入前置或新签走弱
- RPO 集中度：RPO 大幅增长若来自一两个超大单，其质量远低于分散增长（并且附带客户集中度风险，进 F5）

### 1.4 并购与商誉

- 把营收增长拆成**有机 vs 并购贡献**（用被收购方前一年营收近似）。只有有机增长反映权力
- 用股权支付的并购成本容易被低估：按交割时股价折算真实对价，与后续贡献对比
- 商誉与无形资产占总资产比重；历史减值记录；"频繁小额并购冲增速"是常见的增长掩饰手法

### 1.5 自由现金流的质量

- FCF = 经营现金流 − 全部资本开支（含资本化研发）。不要用公司自定义的 FCF 口径
- 拆解 FCF 的来源：其中多少来自营运资本（预收账款增长、应付账款拉长）？这部分在增长放缓时会反向流出
- 检验盈利质量：经营现金流 / (净利润 + SBC)；以及 FCF 与真实 FCF（扣 SBC 后）的差距
- 税盾：早期公司靠历史亏损结转（NOL）少缴税，成熟期税率会跳升。反向 DCF 的终局利润率必须用**正常化税率**

## 2. 增长质量拆解

增长必须拆到能回答"这个增速可持续吗"：

| 拆解维度 | 怎么拆 | 高质量 | 低质量 |
|---------|-------|-------|-------|
| 来源 | 有机 / 并购 / 提价 / 汇率 | 有机为主 | 主要靠并购或一次性提价 |
| 量价 | 客户数×单客户支出 | 量价齐升，或量增为主 | 只有价增（涨价维持增速，量已停滞） |
| 客户结构 | 新客 vs 老客扩张（NRR） | 老客扩张贡献大且 NRR 稳定 | 全靠新客，NRR 走低 |
| 净新增趋势 | 逐季净新增 ARR/客户数（不看累计值） | 净新增绝对额上升或持平 | 净新增连续多季下滑（增速下行的最早信号） |
| 获客方式 | 自然增长占比、销售效率（净新增 ARR / 销售费用） | 自然增长占比上升，销售效率稳定 | 增长靠补贴、免费额度、渠道压货换来 |
| 留存质量 | GRR（不含扩张）与 NRR 分开看 | GRR 高说明产品真被需要 | NRR 靠涨价撑高而 GRR 在跌 |

必查：**增速的分母效应**。营收基数扩大后增速自然下滑属正常，判断权力应看份额与净新增额，而非增速本身。

## 3. 分原型量化门槛表

按第 0 步的分档取对应列。达标记 ✅，不达标记 ❌，数据缺失记 ❓。门槛是判断参照而非硬性红线，偏离时要给结构性理由。

| 指标 | B 订阅软件 | C 消费互联网 | D 交易市场 | E 半导体硬件 | F AI 基础设施 |
|------|-----------|-------------|-----------|-------------|--------------|
| 毛利率 | ≥ 75%（高用量型 ≥ 65%） | ≥ 70% | ≥ 50%（按净收入口径） | 周期中值 ≥ 40% | 推理业务 ≥ 50% |
| 留存 | NRR ≥ 110%，GRR ≥ 90% | 次年用户留存与时长不下滑 | 双边留存均 ≥ 70% | 料号生命周期 ≥ 3 年 | RPO 覆盖 ≥ 1 年产能 |
| 获客回本 | CAC 回本期 ≤ 24 个月 | 获客边际成本不高于 ARPU 增速 | 单笔贡献利润为正且回本 ≤ 12 个月 | — | — |
| 增长效率 | Rule of 40（增速 + 真实 FCF 利润率）≥ 40 | ARPU 与用户数至少一项在增长 | GMV 增长不靠 take rate 让利 | 超越行业周期的份额增长 | 单位算力收入不下滑 |
| 盈利质量 | 真实 FCF（扣 SBC）为正或 3 年内可见 | 真实 FCF 为正 | 真实 FCF 为正 | 周期中值 ROIC ≥ 15% | 折旧年限保守下仍为正 |
| 稀释 | SBC/营收 ≤ 20%，股本年增 ≤ 2% | SBC/营收 ≤ 15% | SBC/营收 ≤ 15% | SBC/营收 ≤ 10% | SBC/营收 ≤ 15% |
| 集中度 | 前十大客户 ≤ 25% 营收 | 前十大广告主 ≤ 25% | 前十大商户 ≤ 25% GMV | 单一客户 ≤ 30% | 单一客户 ≤ 30% RPO |
| 专项 | 按座席收费的公司：AI 减员对座席数的影响 | 年轻用户群份额趋势 | 多栖率与脱媒迹象 | 库存天数 vs 交期、周期位置 | 循环交易与关联方敞口 |

## 4. 未盈利公司专项：到 FCF 的路径

亏损不是否决项，**说不清怎么不亏才是**。要求给出可量化的路径，缺任何一环标 ❓ 并在评分中扣分：

1. **当前毛利率 → 成熟期毛利率**：靠什么改善（规模摊薄、产品结构、自建替代外采、定价），改善幅度的可比参照是谁
2. **费用率收敛路径**：S&M / R&D / G&A 占营收比的当前值与成熟期目标值，以及收敛速度（历年趋势外推是否支持）
3. **盈亏平衡所需规模**：达到真实 FCF 转正需要多少营收？按当前增速要几年？该营收对应的市场份额是否合理
4. **期间融资需求与稀释**：现金 + 可动用融资额度 / 年度真实自由现金流出 = 现金跑道（月）。跑道 < 24 个月且资本市场关闭时无退路 → 进 F5 资金链风险
5. **规模不经济的排查**：有没有随规模上升反而恶化的成本项（内容成本、算力成本、客服人力、坏账）？如果有，增长不会带来盈利

## 5. 单位经济硬开关（F3 的唯一否决触发器）

以下三条任一不成立 → 🚨 F3 否决，不走降级。这三条是"生意本身是否成立"的问题，与"现在是否赚钱"无关：

- **① 边际贡献为正**：毛利 − 增量获客与服务成本 > 0，且随规模改善。多卖一单位就多亏一单位、且看不到反转机制的生意不是好生意，只是补贴换收入
- **② 获客成本可回本**：CAC 回本期可测算且显著短于客户生命周期。算不出来（因为留存数据不披露、客户生命周期未知）→ 标 ❓ 并按不成立处理，除非有强替代证据
- **③ FCF 转正不需要不可得的规模**：倒推所需营收，对照可服务市场规模与合理份额上限。若需要"占领整个行业"或"持续无限融资"才能转正 → 不成立

判定时明确写出三条各自的结论与依据；触发否决的写明是哪一条。

## 6. F3 评分锚点

| 分数 | 标准 |
|------|------|
| 9–10 | 真实 FCF（扣 SBC）利润率优秀且在改善；有机增长为主；门槛表全部达标；净新增额上升；稀释温和 |
| 8 | 真实 FCF 为正；有机增长为主；门槛表主要项达标；净新增持平 |
| 6–7 | 真实 FCF 为正或路径清晰可量化；门槛表部分不达标但有结构性解释；增长质量尚可 |
| 5 | 报表盈利但真实 FCF 勉强/为负；或增长明显靠并购与提价；或关键指标停止披露（❓） |
| 3–4 | 单位经济成立但门槛表大面积不达标；稀释失控（SBC 超过真实 FCF）；净新增连续下滑 |
| 0–2 | 单位经济硬开关任一不成立（此时为 🚨 否决，评分只用于记录严重程度） |

评分依据必须写明：用了哪种 SBC 处理法、真实 FCF 与报表 FCF 的差额、门槛表达标情况、以及为何不给更高/更低一档。
