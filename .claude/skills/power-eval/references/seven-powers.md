# 七种权力（7 Powers）判定标准

F2 的详细检验标准。每一项判定都必须给出具体证据，禁止用形容词代替证据。

## 目录

1. Power 的定义：Benefit + Barrier
2. 七种权力逐条判定
3. 权力形成阶段（Power Progression）
4. 权力方向判断
5. 伪权力清单
6. F2 评分锚点

## 1. Power 的定义：Benefit + Barrier

> Power = 能持续产生超额回报的条件。它必须同时包含两半：**Benefit**（这家公司比竞争者多赚在哪：更高价格、更低成本、更少资本占用）与 **Barrier**（竞争者为什么不能靠花钱和模仿把它抹掉）。

判定纪律：

- 成立的每一条权力，**必须分别写出 Benefit 与 Barrier 两句话**，各带证据。缺 Barrier 的一律记"❌ 无"——那是产品优势，不是权力
- Barrier 的合格形式只有三类：① 复制它需要的时间/资本/积累是竞争者不划算承担的；② 竞争者的现有商业模式使它**不能**跟进（不是不想）；③ 资源本身有限且已被锁定
- "竞争者做不好"不是 Barrier，"竞争者做了会亏"才是
- 一家公司可有多条权力；多条权力相互加强（一条的成果喂养另一条）是**最强信号**，在备忘录中明确指出加强链条
- 没有任何一条同时具备 Benefit 与 Barrier → F2 不超过 4 分，且触发 🚨 否决

## 2. 七种权力逐条判定

### ① 规模经济（Scale Economies）

单位成本随规模下降，且领先者的规模差距无法被追赶者用价格战抹平。

- **合格证据**：单位成本（每用户/每次推理/每片晶圆/每笔交易）与第二名的差距 ≥ 10% 且持续多年；固定成本占比高（研发、数据中心、内容库）而边际成本低；规模差距的来源可解释（分摊研发、采购议价、集群利用率、物流密度）
- **不合格**：营收规模大但单位成本没有优势；成本优势来自暂时的补贴、汇率或一次性采购合同
- 科技语境的常见形态：研发分摊（同一份代码卖给更多客户）、数据中心利用率、内容/内容库摊销、区域密度（配送、维修网络）
- 陷阱：**规模经济必须有"最小有效规模"上限**。如果 5% 份额的玩家已经拿到 90% 的成本优势，那么规模不是权力

### ② 网络经济（Network Economies）

用户越多，产品对每个用户的价值越高，后来者即使产品更好也难以启动。

- **合格证据**：单用户价值随网络规模上升的可观测证据（匹配成功率、内容可得性、集成数量）；竞争者获客成本显著更高；**多栖成本高**（用户不能同时用多个）
- **不合格**：用户数大但用户之间没有交叉价值（如单机工具软件）；用户可低成本多栖（同时挂三个平台）
- 必查：**是否已过临界质量**。未过临界点的"网络效应"只是烧钱；判断依据是自然增长（非付费获客）占比是否在上升
- 必查：网络是全局的还是局部的。局部网络（按城市、按行业、按语言分割）可被区域性对手逐块攻破，权力远弱于全局网络

### ③ 反定位（Counter-Positioning）

新进入者采用了一种新商业模式，在位者**因为自身模式的附带损害而不能跟进**。这是唯一一种"挑战者专属"的权力，也是最容易被忽略的一种。

- **合格证据**：在位者跟进会直接摧毁其现有利润池（渠道冲突、现有产品自我蚕食、现有客户合约反噬）；在位者的公开言行显示它认识到威胁但仍不跟进（"理性的不作为"）
- **不合格**：在位者只是反应慢、组织笨（那是执行差距，会被修补）；新模式在位者其实可以低成本平行运营
- 判定方法：站在在位者 CFO 的位置算一遍——跟进会让它当期损失多少利润、失去多少渠道。算出来"跟进不划算"才成立
- 时效性：反定位是**有保鲜期的权力**。一旦在位者的旧利润池已经萎缩到不值得保护，它就会跟进。必须评估"保鲜期还剩多久"

### ④ 转换成本（Switching Costs）

客户更换供应商需付出实际代价。分三类，逐类给证据：

- **财务型**：预付、长约、许可沉没成本
- **流程型**：数据模型重建、系统集成重写、员工重训、合规重认证、停机风险
- **关系型**：与供应商团队的协作深度、行业内的人才技能锁定（会用这套工具的人多）
- **合格证据**：客户留存（GRR）≥ 90%/年且大客户留存更高；NRR ≥ 110%；具体迁出案例的工作量与耗时；产品作为**系统记录（system of record）**保存客户的关键数据
- **不合格**："客户习惯了"、"换起来麻烦"（无量化留存与迁出代价）；数据可一键导出且集成靠标准协议
- 科技专项陷阱：云时代与开放 API 系统性降低了转换成本。判断时要问"三年前迁出的代价 vs 现在"，方向下行的要标 ⚠️

### ⑤ 品牌（Branding）

同样的东西，因为品牌可以卖更高的价，且这种溢价来自长期一致的体验累积，短期广告买不到。

- **合格证据**：同规格产品长期溢价 ≥ 20% 且份额稳定；溢价在竞争加剧时不收窄；品牌的心理锚点明确（不确定性降低——买它不会出错；或身份认同）
- **不合格**：知名度高但无溢价；广告投入大（那是成本不是权力）；口碑好但客户仍按价格选择
- 科技语境说明：**企业软件的品牌通常表现为"采购安全感"**（选它不会被问责），这是真实的且非常耐久；消费科技的品牌溢价则更依赖产品代际的持续领先
- 必查代际转移：新一代用户是否继承了上一代的品牌认知

### ⑥ 独占资源（Cornered Resource）

以优惠条件获取一项别人拿不到的有价值资源。

- **合格证据**：排他性的具体形式（专利与到期时间表、独家授权/分发合约与期限、稀缺牌照与频谱、锁定的电力与场地、专有数据集及其不可重建性、无法被挖走的核心团队与其锁定机制）
- **不合格**："我们有很多数据"——必须证明：① 数据直接改善产品且形成正反馈；② 竞争者无法通过公开数据、合成数据或购买替代；③ 数据的边际价值没有很快饱和
- 必查排他性的**期限**。所有独占资源都有期限（专利到期、合约续签、人才流动），到期后权力归零。写明剩余年限
- 关键人才作为独占资源要格外谨慎：人会离开。除非有制度性锁定（股权、团队规模效应、组织知识沉淀），否则不计分

### ⑦ 流程优势（Process Power）

组织内部长期积累的做事方式，带来更高质量/更低成本，且**因为需要漫长的实践积累而无法被复制或收购**。

- **合格证据**：可量化的持续领先（良率、交付速度、事故率、迭代频率）；领先已持续多年且竞争者公开尝试模仿但未追上；优势依附于组织流程而非某个人或某台设备
- **不合格**：只是当前团队强；优势可通过购买同款设备/挖人/买软件快速获得
- 判定关键：**"钱能不能买到"**。买得到的是能力，买不到且必须"熬"出来的才是流程优势
- 这是最稀有也最难证伪的一种权力，倾向从严：没有多年可量化的领先记录，判 ⚠️ 存疑而不是"有"

## 3. 权力形成阶段（Power Progression）

权力不是随时可以建立的，它主要在**行业结构剧烈变化的窗口期**形成（新技术起飞、新平台出现、需求形态改变）。判断公司处于哪个阶段：

| 阶段 | 特征 | 投资含义 |
|------|------|---------|
| 起飞期（权力正在形成） | 行业高速增长、格局未定、公司份额快速上升 | 权力尚未在财务上体现，估值反映的是叙事；判定重点是"正在形成的权力是哪一条、Barrier 正在长出来吗" |
| 稳定期（吃既有权力） | 增速回落、格局稳定、利润率高且稳 | 权力可验证，财务证据充分；风险是代际变迁使既有权力折旧 |
| 折旧期（权力在流失） | 份额或 take rate 或毛利率持续下滑、需要靠并购维持增长 | 便宜通常是陷阱；此时"低估值"不是安全边际 |

必答：**这家公司现在还有没有建立新权力的窗口？** 成熟公司若已无窗口，其权力只会随时间折旧，F6 的终局假设必须相应保守。反之，处于起飞期的公司要在 F3 明确"权力形成的资金消耗与时间表"。

## 4. 权力方向判断

回答：**5–10 年后这条权力更强还是更弱？** 每个信号都要给可观测指标。

变强的信号：份额持续提升、提价/take rate 提升且未流失客户、NRR 上升、自然增长占比上升、竞争者退出或转向、生态第三方投入增加、单位成本差距拉大。

变弱的信号：份额或 take rate 下滑、NRR 下滑、获客成本上升而 ARPU 不变、必须靠并购维持增速、开源等价物质量追平、大客户开始自建、标准化协议降低迁出成本、核心专利/合约临近到期、核心团队流向竞争者。

## 5. 伪权力清单

以下常被当作科技公司的护城河，**单独存在时不计分**：

- **技术领先一代**：没有 Barrier。一代领先会被下一代清零，除非转化为专利墙、成本曲线或生态锁定
- **先发优势**：先发本身不是权力，只是获得权力的机会。要问"先发已经换成了哪一条权力"，换不出来就是没有
- **用户量大**：份额是结果不是原因。必须证明用户之间存在交叉价值（网络经济）或摊薄了固定成本（规模经济）
- **数据"很多"**：见 §2-⑥ 的三条检验。大部分"数据护城河"经不起"竞争者能否用别的方式拿到等效数据"这一问
- **热门赛道 / TAM 巨大**：增长吸引竞争，行业增长 ≠ 公司权力。TAM 大只意味着竞争者也看得见
- **明星创始人 / 优秀团队**：属 F4（管理层），不属权力。权力必须附着在生意上而不是人身上
- **资本雄厚 / 现金多**：钱是通用资源，竞争者也能融到。除非资本开支本身锁定了稀缺资源（见独占资源）
- **可 fork 的开源生态**：如果社区可以分叉且商业公司不控制关键分发或托管，"生态"不构成 Barrier
- **合作伙伴名单长**：非排他的合作关系随时可复制
- **AI 能力/自研模型**：除非有独占的数据、分发或成本优势，否则通用模型能力是所有人都能买到的输入

## 6. F2 评分锚点

| 分数 | 标准 |
|------|------|
| 9–10 | ≥ 2 条权力成立且相互加强（一条的成果喂养另一条），Benefit 与 Barrier 均有硬证据，权力方向变强，且仍处在可建立新权力的窗口 |
| 8 | 1 条强权力（Barrier 明确、多年可验证）+ 权力方向持平或变强 |
| 7 | 权力成立但来源单一且 Barrier 依赖期限性资源（专利/合约/保鲜期内的反定位），或方向不明 |
| 6 | 权力大概成立但证据不足（关键量化缺失），或仅在局部市场/局部网络成立 |
| 5 | 有明确产品优势但 Barrier 说不清（🚨 触及否决线，需在评分依据中说明为何仍给 5 而非更低） |
| 3–4 | 无任何一条权力同时具备 Benefit 与 Barrier；靠执行力与营销竞争 |
| 0–2 | 唯一权力正在被证据确认地瓦解（份额/take rate/毛利率同步下滑，开源或通用模型已追平） |

评分依据必须逐条对照：给出成立的权力条数、每条的 Barrier 类型、方向判断、以及为何不给更高/更低一档。
