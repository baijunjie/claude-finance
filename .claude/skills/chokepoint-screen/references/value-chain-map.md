# AI / 人形机器人价值链地图（收费站定位）

本文件是 F0 层级预筛的领域底稿：把机器人价值链拆层，标明每层的**收费站属性**，并为收费站层给出**候选公司起点池**（美股 / 日股，注明上市/未上市）。

> 说明：具体份额、财报、上市状态数字**时效性强，筛选时必须联网核实**（本文件只给出量级与格局定性，不作为最终数字来源）。候选池是起点，不是穷举——筛选时可增补。

## 一、价值链分层与收费站属性

从"最像收费站"到"最不像"排列：

| 层级 | 代表环节 | 收费站属性 | 判定理由 |
|------|---------|-----------|---------|
| 算力 + 软件生态（"英伟达位置"） | 边缘推理芯片、仿真到现实平台、具身基础模型/工具链 | ✅ 收费站（但属"英伟达位置"，单列） | 生态锁死潜力最大；但逻辑不同于实体零部件寡头 |
| 精密传动核心零部件 | 谐波减速器、RV减速器、行星滚柱丝杠 | ✅ 强收费站 | 专利+工艺+良率壁垒，全球寡头，整机厂难自研 |
| 精密运动 / 电机 | 框架式力矩电机、无框电机、伺服 | ✅ 收费站（部分） | 高端无框力矩电机壁垒高；通用伺服偏商品化 |
| 高端感知 | 六维力/力矩传感器、机器人级编码器 | ✅ 收费站 | 玩家少、壁垒高、是灵巧操作命门 |
| 新兴感知 | 触觉传感器 / 电子皮肤 | ⚠️ 收费站在形成中 | 壁垒可能很高，但多为未上市初创，标的不可投 |
| 机器视觉 | 3D 视觉、机器视觉相机/软件 | ⚠️ 部分收费站 | 少数龙头有壁垒，但竞争者多、赛道边界宽 |
| 直线传动通用件 | 直线导轨、滚珠丝杠 | ⚠️ 部分 | 龙头有优势但相对成熟、国产替代活跃 |
| 电池 / 电源 | 动力电池、电源管理 | ❌ 商品化层 | 与 EV 供应链重叠，机器人专属性弱、竞争充分 |
| 整机本体 | 人形/工业机器人整机品牌 | ❌ 终端赌局 | "造应用的"，是终端赢家之争，非横向收费站 |

## 二、收费站层的候选公司起点池

### 1. 精密减速器（强收费站）

- **谐波减速器**（人形旋转关节核心）：Harmonic Drive Systems（东京 6324，日）为全球主导；追赶者含中国厂商（绿的谐波等，多在 A 股）。
- **RV / 摆线减速器**（重载工业关节）：Nabtesco（东京 6268，日）主导；Sumitomo（住友）等参与。
- **壁垒**：齿形专利、材料热处理、精度一致性、量产良率——整机厂自研需多年工艺积累。是本框架最典型的"海力士位置"候选层。

### 2. 直线执行 / 丝杠（收费站强度取决于品类）

- **行星滚柱丝杠**（人形直线执行器核心，重点关注）：良率低、成本高、供给最紧的环节之一；能稳定量产的玩家少。可能玩家含 THK（6481，日）、日系与欧系精密丝杠厂；筛选时核实谁真正上量。
- **滚珠丝杠 / 直线导轨**（相对成熟）：THK（6481）、NSK（6471，日）龙头，但国产替代活跃，属"部分收费站"。

### 3. 精密电机（部分收费站）

- **框架式/无框力矩电机、集成关节执行器**：高端无框力矩电机壁垒较高。
- 候选：Nidec（6594，日，注意 EV 电机等业务稀释纯度）、Minebea Mitsumi（6479，日，小型电机+轴承+传感，纯度需查）；美股 Novanta 旗下 Celera Motion（无框电机+编码器）、Allient（ALNT）。

### 4. 高端感知（收费站）

- **六维力/力矩传感器**（灵巧操作命门）：玩家少、壁垒高。ATI Industrial Automation（隶属美股 Novanta / NOVT）是全球主要供应商之一；另有德系等。
- **机器人级编码器**：光学/磁编码器，高端玩家集中。Novanta（Celera Motion）、日系厂商。
- **触觉传感器 / 电子皮肤**：壁垒可能很高，但当前多为**未上市初创**，标的多不可投（F0 判 ❌ 不可投或转观察）。

### 5. 机器视觉（部分收费站）

- 机器视觉/3D 视觉：Cognex（CGNX，美）、Keyence（6861，日，但为宽口径工厂自动化，纯度需查）。竞争者较多，收费站强度弱于减速器/力传感器。

### 6. 算力 + 软件生态（"英伟达位置"，单列）

- 边缘推理 + 仿真 + 具身模型工具链：Nvidia（NVDA）以 Jetson/Thor + Isaac + GR00T 占位最强；属"英伟达位置"，单列不与实体零部件寡头混排。
- 边缘视觉 AI SoC：Ambarella（AMBA）等。

## 三、易被误列、应重点用否决项检验的公司

- **整机厂 / 既造零件又造整机**：Fanuc（6954）、Yaskawa（6506）——同时卖伺服/控制器与整机机器人，与客户竞争，横向性（F1）存疑，重点用 F1 检验。
- **纯度被稀释的大集团**：Nidec（EV 电机为主）、Minebea Mitsumi、Keyence（宽口径 FA）、Sensata、Rockwell、Teradyne（含 Universal Robots 整机）——机器人/目标环节占营收比例低或本身含整机业务，重点用 F5 纯度与 F1 检验。
- **需求押单一爆款或格局未定**：部分激光雷达、触觉初创——用 F3/F4/F5 检验格局与盈利质量。

## 四、使用提示

- 候选池按"落在收费站层 + 有可投标的（上市）"筛选；未上市的强环节（部分触觉/丝杠玩家）记为 ❌ 不可投并在报告中说明"最强环节不在二级市场"。
- 中国 A 股龙头（如谐波、丝杠国产厂）不在美股/日股范围，但作为**低价替代威胁**在 F5 中评估其对候选公司份额/毛利的侵蚀。
- 每家公司的份额、毛利率趋势、机器人敞口占比在应用时联网核实并标注数据时间与来源。
