## 1. 卡脖子壁垒：自研 / 替代测试（F2 核心）

核心问题：**整机厂能不能绕开它？** 分两条追问，任一条"能轻易绕开"即壁垒不成立。

**（1）能不能自研？**
- 整机厂自建这一环，要多久、要多少累计资本、良率能不能爬到可用水平？
- 有没有已上量的自研先例？（有厂商自研成功并稳定供货 = 壁垒被证伪的强信号）
- 关键判据：自研的**时间与良率壁垒**。能在 1–2 年内做出可用品 → 弱壁垒；需要 5–10 年工艺积累且良率长期卡在低位 → 强壁垒。

**（2）能不能替代/绕过？**
- 有没有别的技术方案实现同样功能、且整机厂愿意切换？（如用行星减速器替代谐波、用直驱替代减速器）
- 替代方案的性能/成本代价有多大？代价小 → 弱壁垒。

判定：明确"绕不开（强壁垒）/ 部分可绕（中）/ 易绕开（无壁垒）"，各附证据或数据缺口 ❓。

## 2. 卡脖子壁垒：壁垒类型与评分锚点（F2）

识别壁垒类型，每类给合格证据：

| 壁垒类型 | 合格证据示例 | 不合格的"证据" |
|---------|-------------|---------------|
| 专利 + 工艺 | 核心专利 + 难以复制的加工工艺（如谐波齿形、材料热处理）；专利到期表 | "有很多专利"（不区分核心与外围） |
| 良率 / 制造 | 关键工序良率行业普遍低、龙头显著更高；产线爬坡以年计 | "工艺先进"（无良率对比） |
| 材料 / 上游 | 依赖稀缺材料或独家上游，龙头锁定供给 | "用料好" |
| 精度 / Know-how 积累 | 精度指标领先且靠长期数据/工艺积累，非砸钱可速成 | "技术领先"（未转化为专利墙或成本差） |
| 生态 / 认证锁死 | 嵌入客户设计与认证体系，切换需重新认证/停产；开发工具链绑定 | "客户习惯了"（无切换成本量化） |

**F2 评分锚点：**

| 分数 | 标准 |
|------|------|
| 9–10 | 绕不开（自研与替代均代价极高）+ ≥ 2 类壁垒相互加强（如专利+良率+精度积累），龙头工艺代差明显 |
| 8 | 绕不开 + 1 类强壁垒，短期无可用自研先例 |
| 7 | 壁垒成立但来源单一，或已出现追赶者但尚未上量 |
| 5–6 | 有领先但可被复制，自研/替代代价中等 |
| 3–4 | 可外包组装 / 通用件，靠运营效率竞争 |
| 0–2 | 无壁垒，已被广泛自研或替代 |

< 7 分即 F2 否决（排除）。

## 3. 寡头结构判定（F3）

- 列出该环节全球能**稳定量产供货**的玩家（区分上市/未上市、国别），给龙头与前三份额（数字，标数据来源与时间）。
- 判据：
  - ✅ 通过：全球 1–3 家寡占，龙头份额高（大致 ≥ 40%）且多年稳定或提升。
  - ⚠️ 存疑：4–6 家，或集中度在下降（新进入者上量中）。
  - 🚨 否决：十几家以上充分竞争，或格局正被快速打散（份额年年被侵蚀）。
- 注意区分"**格局集中且稳定**"与"**行业高增长中的暂时集中**"——后者会吸引进入，集中度不可持续（见 §6 伪收费站）。

## 4. 盈利质量与定价权（F4，降级项）

戳穿"垄断了份额、却赚不到钱"的伪收费站。核心问题：**这个垄断真的变现了吗？还在变现吗？**

- **毛利率 / 营业利润率**：水平（同行对比）+ **趋势**（近 3–5 年上升/持平/下滑）。持续下滑是定价权流失的头号红旗，即便份额还在。
- **ROIC**：是否持续高于资本成本；靠杠杆撑起的 ROE 要用 ROIC 戳穿。
- **提价记录**：历史提价次数/幅度及量的反应；能提价不流失客户 = 定价权强证据。
- 反面特征：靠降价保份额、大客户年度压价、招标同质化采购、毛利率被国产替代逐年压缩。

判定：⚠️ 降级（非否决）——份额到位但盈利质量差或在恶化 → 结论降为"观察"。评分锚点：≥ 8 = 高毛利且稳定/提升 + 有提价证据；6–7 = 盈利尚可但趋势走平或证据不足；< 6 = 盈利质量差或毛利率明显下滑 → 降级。

## 5. 抗颠覆性与需求纯度（F5）

检验"海力士类比会不会被打破"。前两项是专杀收费站的敌人（否决项），后两项为降级/存疑。

**（1）抗垂直整合（否决项）**
- 哪些核心整机厂有动机+能力把这一环内化？（自研执行器、自研电机的整机厂是最大威胁）
- 判据：内化已发生且不可逆、份额将大幅流失 → 🚨 否决；有动机但壁垒挡住内化（回到 F2 自研测试）→ ✅ 通过；在途未定 → ⚠️ 存疑（进入 Pre-mortem）。
- 关键洞察：机器人不像 GPU——大整机厂有动机自研电机/丝杠/执行器。要押的是"**未来仍会外采**"的环节，即 F2 壁垒足以挡住内化的环节。

**（2）抗低价替代（否决项）**
- 国产/低成本玩家能否在"可接受性能"下把它打成微利？
- 判据：已把毛利率打穿且不可逆 → 🚨 否决；替代在途、性能尚有差距 → ⚠️ 存疑；性能差距结构性存在且短期无法弥合 → ✅ 通过。
- 关键洞察：纯机械件即使今天垄断份额，也可能被低价替代打成微利（有份额没利润）；能扛住的护城河通常来自**专利+极端制造工艺**或**生态/认证锁死**，而非单纯份额领先。

**（3）技术颠覆**
- 有没有替代技术路线正在取代这个环节本身（如直驱电机取代减速器、软体/新型驱动取代传统执行器）。即便尚未盈利，路线出现即为方向性风险。

**（4）需求纯度（降级项）**
- **需求锚定**：需求是否随行业总量增长，而非押单个爆款整机的成败。锚定总量 = 更稳的收费站。
- **营收纯度**：该收费站业务占公司总营收比例。占比高 = 纯正标的；占比低（被 EV、工控、消费电子等其他业务稀释）→ ⚠️ 降级为"观察"，说明这是"沾边"而非"纯正"敞口，并估算纯度区间。

## 6. 伪收费站警示

以下常被误认为"海力士位置"，单独存在时不计分，甚至应否决：

- **热门赛道里的高增长公司**：增长吸引竞争，行业增长 ≠ 公司护城河；高增长中的集中度往往不可持续。
- **有份额没利润**：份额第一但毛利率被逐年压缩，是被商品化的信号，不是收费站。
- **绑定单一整机厂的"关联供应商"**：整机厂赢它才赢——这是纵向下注，不是横向收费站。
- **一代技术领先**：未转化为专利墙/成本差/生态锁死的技术领先，会被下一代清零（柯达、诺基亚都曾领先）。
- **既造零件又造整机的整机厂**：与客户竞争，其他整机厂会扶持替代供应商，横向性存疑。
- **"英伟达位置"冒充"海力士位置"**：算力+软件生态层是另一种收费站（生态锁死），单独标注，不与实体零部件寡头混排评分。
