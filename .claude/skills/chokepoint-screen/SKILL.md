# 卡脖子零部件筛选（Chokepoint Screen · 收费站 / 卖铲人）

寻找一条产业链里"最像海力士 / 台积电位置"的公司：**不押终端赢家，只押所有玩家都必须经过的收费站。** 内置 AI 机器人价值链作为默认赛道，框架本身可迁移到任何产业链。

评估目的不是给热门标的找买入理由，而是**寻找否决它的理由**——只有同时具备"横向 + 卡脖子 + 寡头 + 能变现 + 抗颠覆"的公司，才配得上"海力士位置"这个说法。

## 收费站位置的五条基因（筛选即验证这五条）

英伟达和海力士能赢，不是因为它们造终端产品，而是因为它们站在一个所有人都绕不开的收费站上。拆成可检验的五条：

1. **横向而非纵向**——卖给全行业，且（基本）不与客户抢终端市场。谁家整机赢不重要，都得买它。
2. **卡脖子瓶颈**——技术/制造壁垒极高，客户想自研也做不出或不划算。
3. **寡头结构**——全球仅 1–3 家能供，天然定价权。
4. **能把垄断变现**——真的赚到高毛利/高 ROIC，而不是"垄断了份额却被打成微利"。
5. **抗颠覆**——护城河能扛住整机厂垂直整合与低价（国产）替代，需求锚定行业总量而非单个爆款。

## 筛选原则

- **结构先于个股**：先判断"这一层是不是收费站"（F0），再判断"这家公司在这一层是不是收费站主"。不在收费站层的公司直接排除，不进入个股过滤器。
- **否决制，非加权平均**：任一否决层不及格即整体排除，高分项不能弥补被否层。这是排除法，不是凑总分。
- **证据驱动**：每个判定必须有具体证据（份额数字、毛利率轨迹、提价记录、专利/良率事实），禁止用形容词代替证据。"壁垒高"不是证据，"全球三家供货、份额 60%、毛利率 40% 且五年稳定"才是。
- **区分两个位置**：算力 + 软件生态层（如 Nvidia Jetson/Isaac）是"**英伟达位置**"，本 skill 专筛"**海力士位置**"（高壁垒寡头的实体零部件/材料）。命中英伟达位置的公司要单列标注，不与海力士位置混排。
- **承认不知道**：最强的卡脖子环节常由**未上市公司**或**大集团里的小事业部**占据。标的不可投（未上市）或敞口被稀释（纯度低）是合法结论，比硬凑一个"可投"标的更有价值。

## 工作流程

### 第 0 步：确定赛道与价值链定位（层级预筛）

1. 确认赛道（默认 = AI / 人形机器人；用户另指定则用其赛道，此时价值链需临时构建）。
2. 读取 [references/value-chain-map.md](references/value-chain-map.md)，把产业链拆层，对每一层判定其**收费站属性**（是不是所有整机厂都要买、能不能被自研/替代、供给是否集中）。
3. 只有落在**收费站层**的环节才继续，商品化层（同质化、充分竞争、随整机厂垂直整合而内化）直接标注"非收费站层，排除"。
4. 在收费站层内，构建**候选公司清单（美股 + 日股）**，逐家进入 F1–F5。清单来源优先级：用户提供 > 联网搜索（当前份额/财报/上市状态）> 模型已有知识（注明数据截止时间）。

### 第 1 步：横向性过滤器（F1，否决项）

核心问题：**它卖给全行业，还是绑死在一家整机厂？它会不会与自己的客户抢终端市场？**

- ✅ 通过：横向供应多家整机厂，且不生产与客户直接竞争的终端机器人。
- 🚨 否决：本质是某一家整机厂的自研/关联供应商（营收高度依赖单一大客户），或本身就是整机厂（既卖零件又卖成品机器人，与客户竞争）。
- 既造零件又造整机的"混合体"（如部分伺服+机器人一体的公司）单独说明：其零部件外供比例越高越接近横向，越以自家整机为主越应否决。

### 第 2 步：卡脖子壁垒过滤器（F2，否决项，核心）

读取 [references/filter-criteria.md](references/filter-criteria.md) §1–§2，按其中的**壁垒类型**与**自研/替代测试**逐项检验：

- **自研/替代测试**：整机厂能不能自己做、或换个方案绕过去？代价（时间、良率、认证、成本）有多大？绕得过去 → 不是卡脖子。
- **壁垒类型识别**（专利+齿形工艺 / 良率 / 材料 / 精度积累 / 生态锁死），每类给证据。
- 🚨 否决：本质是可外包的组装/通用件，无结构性壁垒；壁垒仅来自"暂时领先一代技术"。

### 第 3 步：寡头结构过滤器（F3，否决项）

读取 [references/filter-criteria.md](references/filter-criteria.md) §3：

- 该环节全球能稳定供货的玩家数量、龙头份额（给数字）。
- ✅ 通过：全球 1–3 家寡占，龙头份额高且多年稳定。
- ⚠️ 存疑：4–6 家，集中度在下降。
- 🚨 否决：十几家以上充分竞争，或格局正被快速打散。

### 第 4 步：盈利质量与定价权过滤器（F4，降级项）

读取 [references/filter-criteria.md](references/filter-criteria.md) §4。这一步戳穿"垄断了份额、却赚不到钱"的伪收费站：

- 毛利率/营业利润率水平与**趋势**（持续下滑是定价权流失的红旗）。
- ROIC 水平；历史提价记录及量的反应。
- ⚠️ 降级（非否决）：份额到位但盈利质量差或在恶化 → 结论降为"观察"，不排除。

### 第 5 步：抗颠覆性与需求纯度过滤器（F5）

读取 [references/filter-criteria.md](references/filter-criteria.md) §5，这一步检验"这个类比会不会被打破"，含两个专杀收费站的敌人：

- **抗垂直整合**（否决项）：核心整机厂（如自研 Optimus 执行器的玩家）有多大动机与能力把这一环内化？内化不可逆且份额将大幅流失 → 🚨 否决。
- **抗低价替代**（否决项）：国产/低成本替代能否在可接受性能下把它打成微利？已发生且不可逆 → 🚨 否决；在途未定 → ⚠️ 存疑（进入 Pre-mortem）。
- **技术颠覆**：有没有替代技术路线正在取代这个环节本身。
- **需求纯度**（降级项）：① 需求是否锚定行业总量而非单个爆款；② 该收费站业务占公司总营收的比例——占比太低（被其他业务稀释）→ ⚠️ 降级为"观察"，说明这是"沾边"而非"纯正"标的。

### 第 6 步：逆向 Pre-mortem（卖铲人如何亏钱）

假设 3–5 年后这笔"海力士位置"的投注亏损，写出 3–5 条最可能的原因（按概率排序，给主观概率区间），每条附当前可见的早期信号与复评触发指标。头部路径通常来自 F5 的两个敌人（垂直整合、低价替代）或需求证伪（爆款没来、行业放量不及预期）。

### 第 7 步：输出筛选文档

按 [assets/screen-template.md](assets/screen-template.md) 生成筛选报告，保存到当前工作目录 `output/chokepoint-screen/<赛道>-<日期>.md`（目录不存在时先创建）。文档含：价值链定位图、候选公司分层清单（核心候选 / 观察 / 排除）、每家评分卡、逆向 Pre-mortem、数据缺口与来源。

## 判定标识（全文统一）

| Emoji | 含义 | 用在哪里 |
|-------|------|---------|
| ✅ | 确认通过 / 确认具备（证据充分的正面判定） | 横向、卡脖子、寡头、盈利质量、抗颠覆各项"是" |
| 🚨 | 确认不利 / 否决项（证据充分的负面判定） | 触发否决的分项（非横向、无壁垒、非寡头、垂直整合/低价替代已发生） |
| ⚠️ | 存疑 / 降级（证据不足或方向不明，可被新证据翻转） | 集中度存疑、盈利质量恶化、纯度不足、抗颠覆在途未定 |
| ❓ | 数据缺口（数据不全、待核实，影响判定可靠性） | 份额/财报为估算值或未核实处、数据缺口列表 |
| ❌ | 不通过 / 无 | 该环节非收费站层、标的不可投（未上市） |

使用规则：分层清单表、每家评分卡的判定列**必须**带标识；正文关键判定（自研测试、份额、定价权、垂直整合/低价替代结论）在判定词后紧跟标识；不在叙述文字中滥用。

## 评分与分层规则（否决制）

| 过滤器 | 判定 | 及格线 |
|--------|------|--------|
| F0 收费站层 | 是 / 否 | 否 → 该公司整体排除（不在收费站层） |
| F1 横向性 | 通过 / 否决 | 否决 → **排除** |
| F2 卡脖子壁垒 | 0–10 | < 7 → **排除** |
| F3 寡头结构 | 通过 / 存疑 / 否决 | 否决 → **排除**；存疑 → 至多"观察" |
| F4 盈利质量与定价权 | 0–10 | < 6 → **降级为"观察"**（不排除） |
| F5-抗颠覆 | 通过 / 存疑 / 否决 | 否决 → **排除**；存疑 → 至多"观察" |
| F5-纯度 | 通过 / 降级 | 稀释 → **降级为"观察"** |

**分层结论：**

- **核心候选（Core）**：F1 横向 / F3 寡头 / F5-抗颠覆全部通过 + F2 ≥ 8 + F4 ≥ 6 + 纯度通过。真正的"海力士位置"标的。
- **观察（Watch）**：否决项全过，但 F4 不及格 / 纯度被稀释 / 存在存疑项（F3 或 F5-抗颠覆判"存疑"）/ 关键数据缺口。方向对，等待验证或更好的介入点。
- **排除（Excluded）**：任一否决项不及格。必须写明**单一首要否决原因**（如"整机厂垂直整合"、"本身是整机厂非横向"、"非收费站层"）。

注意用词：F1/F2/F3/F5-抗颠覆 不及格是"**排除**"；F4 与 F5-纯度 不及格是"**降级**"。

## 注意事项

- 这是**产业链结构选股/研究**框架（找长期结构性赢家的候选池），不是短期择时；具体到单只标的的深度定性+定量，转 `munger-eval`；要判断做多/做空点位与期权赔率，转 `trade-eval` / `call-eval` / `short-eval`。
- 一次筛多家：逐家独立过 F1–F5，最后统一给分层清单与横向对比表，不在单家评估中互相参照妥协。
- 份额、财报、敞口数据时效性强，正文引用处标注数据时间，未核实标 ❓；对有立场的来源（券商推票、公司 IR 口径）注明立场。
- 严格按模板章节标题与固定格式输出，不增删或改写章节标题。
- 本框架输出候选池与结构判断，**不构成投资建议**。
