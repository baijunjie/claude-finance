# 追高回调/利好出尽/稀释风险、Pre-mortem 与退出计划（Filter 4 + 第 6 步）

"反过来想"——做多前先穷尽这笔交易**如何被打爆、如何亏光权利金**。1-2 个月期权窗口里，做多的杀手不是逼空，而是**追高接盘后的回调、利好出尽、拥挤多头踩踏、以及高位增发砸盘**；外加"涨慢于跌"的不对称使 theta 更易拖死慢牛。

## 1. 追高回调 / 超买反转风险

呼应趋势层的短期反转效应（1 个月内，多头版）。核查标的当前是否处于**易回调位置**：
- RSI 极高（如 > 70-80）、连续多根大阳线、相对均线乖离过大（涨太急太远）
- 临近强阻力（前期高点、整数关口、密集成交区上沿）
- 缺口未回补、量价背离（创新高但量能萎缩）

若当前正是超买追高点 → 不立即买 call，等回调企稳、趋势重新确认后再入场（归入 F1 的"有条件通过"或 F5 的入场时机）。

## 2. 利好出尽（sell the news）风险

- 催化剂是否已被市场**充分预期与定价**？兑现日（如财报、产品发布）往往是"买预期、卖事实"的阶段顶。
- 股价是否在催化剂前已大涨透支？
- 规则：已 priced in 的催化剂在 F3 不加分、在此处计为风险；尤其警惕"财报前已大涨 + 高 IV"的组合（利好出尽 + IV crush 双杀）。

## 3. 拥挤多头风险

- 是否人人已满仓看多（卖方一致上调、看涨情绪指标极端、散户抱团/meme）？拥挤的多头一遇边际利空或不及预期，踩踏式获利了结放大回调。
- 资金面：近期涨幅是否主要靠杠杆/情绪资金推动而非基本面买盘？
- 反向情绪信号：极端看多往往对应短期超买，需与 F1 趋势强度权衡。

## 4. 稀释 / 砸盘风险（call-eval 专属）

做多特有、且 short-eval 没有的对称项——直接给涨势盖帽甚至砸盘：

| 风险 | 核查要点 |
|------|---------|
| 高位增发 / 配股 | 公司是否有再融资计划、历史上是否惯于高位增发（股权择时）？ |
| ATM 增发 | 是否有 at-the-market 持续抛售协议在执行（涨多少卖多少，封死上行）？ |
| 可转债转股 | 在外可转债是否临近转股价、转股将稀释并带来抛压？ |
| 限售解禁 | 未来 1-2 个月是否有大额解禁，解禁方成本极低有抛售动机？ |
| 大股东 / 高管减持 | 高位是否出现密集减持、减持计划公告？ |
| 股权激励行权 | 大额行权带来的稀释与抛售 |

任一"巨额增发/解禁在途 + 高位"→ F4 顶格警惕，可单独否决。

## 6. F4 评分锚点（0-10，**越高越安全**）

| 分数 | 标准 |
|------|------|
| 8-10 | 非超买、催化剂未透支、多头不拥挤、无增发/解禁/减持压力 |
| 5-7 | 个别风险中等（如略超买，或有小额解禁），可控但需在退出计划中防范 |
| 3-4 | 多项风险偏高，或当前明显超买/催化剂已大幅 priced in——降级为观察，等回调入场 |
| 0-2 | 顶部派发 / 巨额增发或解禁在途 / 极度超买 / 强 meme → 否决 |

## 7. Pre-mortem 操作方法

假设：**期权到期日，这笔做多亏光了全部权利金。写一篇"事后复盘"解释为什么。**

要求：
- 写出 3-5 条最可能的失败路径，按概率排序
- 每条给出估算概率区间（期权到期前发生的主观概率，如 25%–35%）：概率须与排序一致；用宽区间表达不确定性，不写伪精确单点数字
- 每条注明：当前是否已有早期信号？什么信号出现时应当平仓？
- 失败路径必须具体到机制，常见七类：
  1. **趋势反转**：突破后快速跌回平台/失守关键均线，上升趋势证伪
  2. **追高回调**：超买后的短期反转，未到目标位先被震出
  3. **利好出尽**：催化剂兑现即见顶（sell the news）
  4. **IV crush**：催化剂（尤其财报）落地后 IV 崩塌，方向对但 call 仍亏（见 option-structure.md）
  5. **催化剂落空/反向**：预期的利多未兑现或不及预期
  6. **theta 拖死**：方向对但涨太慢（涨慢于跌的不对称），时间价值衰减跑赢涨幅
  7. **增发/解禁砸盘**：高位再融资或解禁抛压封死上行

## 8. 退出计划（对应"不持有到期、找点位平仓"）

每次做多必须预先写定三条线，落到具体价位/比例，禁止"看情况"：

- **止盈**：标的涨至目标位即平仓——目标位取上方强阻力、前期高点、或涨幅达预期波动的 X%（因涨慢于跌，建议达预期波动的 60-70% 即兑现，不贪到期）。可分批止盈。
- **止损**：标的反向跌破关键支撑（如失守 50 日均线、跌回突破平台内）→ 上升趋势证伪，认赔离场；或权利金回撤达预设比例（如 −50%）强制止损。
- **时间止损**：到期前 ~21 天若论点仍未兑现 → 平仓收回残值，避开 theta 加速衰减区。

退出计划须写进备忘录第七节，并与 F5 选定的到期日/行权价一致。
