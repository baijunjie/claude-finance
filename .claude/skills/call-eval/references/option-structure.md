# 期权结构与赔率（Filter 5）

Filter 5 把前四层的判断翻译成一句话：**这笔看涨期权到底划不划算？** 做**定性 + 关键指标**评估，不做精确 Black-Scholes 定价。核心矛盾：方向对、时间对，但若 IV 太贵、或预期波动已覆盖目标涨幅、或上涨太慢被 theta 吃掉，照样不赚钱。**因"涨慢于跌"的不对称，本层的目标涨幅与赔率门槛要比 short-eval 更保守。**

## 目录

1. IV 水平与 put-call skew（call 的结构性优势）
2. IV crush 陷阱（买 call 的头号杀手）
3. 预期波动 vs 你的目标涨幅
4. Theta 与到期日选择（涨慢于跌 → 更怕 theta）
5. 行权价与盈亏平衡
6. 风险回报比
7. F5 判定锚点

## 1. IV 水平与 put-call skew

- **IV Rank**：`(当前 IV − 过去一年最低 IV) / (过去一年最高 IV − 过去一年最低 IV)`，0-100%。
- **IV Percentile**：过去一年中 IV 低于当前值的交易日占比。
- 判定：
  - IV Rank **低**（如 < 30）✅：call 相对便宜，买方有利。
  - IV Rank **高**（如 > 60）🚨：call 贵，且大概率面临均值回归式 IV 回落（vega 亏损），即使方向对也吃力。
- **put-call skew（call 的结构性优势）**：股票期权普遍存在偏斜——同等虚值程度下，**虚值 call 的 IV 通常低于虚值 put**（市场更怕下跌）。这意味着买 call 在 IV 成本上常比买 put 略占便宜。**但别被高 IV 的题材股/财报前标的反噬**——结构性便宜不等于这只标的此刻便宜。
- 对比 **HV（历史波动率）**：IV 远高于 HV，说明已为大波动定价，你为"已知的期待"付了溢价。

## 2. IV crush 陷阱（买 call 的头号杀手）

- 财报/重大事件**前** IV 显著抬升，**后**无论股价往哪走 IV 急剧回落（crush）。
- 临近财报追 call：若财报后股票只小涨甚至不涨，IV crush 会让 call 大幅贬值——**方向对也亏钱**。做多的题材股 IV 往往比做空标的更高更贵，这一陷阱比 short-eval 更常见、更致命。
- 规则：
  - 若催化剂 = 财报，**避免在财报前一两天追高 IV 买 call**；优先在财报后 IV 回落、PEAD 漂移在途时介入（既吃漂移又避 crush）。
  - 在备忘录中明确标注目标期权是否跨越财报日，以及对应的 IV crush 敞口 🚨。

## 3. 预期波动 vs 你的目标涨幅

用隐含波动估算到期前的"市场预期波动幅度"：

```
预期波动（1 个标准差，到期前）≈ 股价 × IV × √(DTE / 365)
```

- 若你预期的上涨幅度**已经落在**市场预期波动范围内 → 这个涨幅已被 call 价格涵盖，赔率平庸 ⚠️。
- 真正有利的做多：你预期的涨幅（基于趋势目标位 + 戴维斯双击测算）**显著超过**市场隐含的预期波动 ✅。
- **保守化要求**：因"涨慢于跌"，设定目标涨幅时要打折——不要用对称的 put 目标幅度直接镜像，楼梯式上涨往往达不到那么大的幅度。把目标涨幅、预期波动、盈亏平衡涨幅三者并列对比，并取偏保守的目标。

## 4. Theta 与到期日选择（涨慢于跌 → 更怕 theta）

- Theta（时间价值衰减）在到期前最后 ~30 天**加速**，越临近到期、ATM 期权衰减越快。
- 因上涨是慢磨，买 call 比买 put 更需要给时间：
  - **倾向买 ~45-60 DTE 或略长**，给慢磨的趋势/催化剂留出兑现时间；
  - 必要时选**略实值（ITM）**降低时间价值占比、提高 delta，对冲慢磨被 theta 吃掉的风险（代价是权利金更高、杠杆更低）；
  - **在最后 ~21 天 theta 加速前平仓**（呼应退出计划的时间止损）；
  - 不做 < 30 DTE 的短期 call（theta 太凶、容错太低，用户已明确 1 个月内风险过高）。

## 5. 行权价与盈亏平衡

- **行权价选择**：
  - 略实值 ITM：delta 高（如 0.6-0.7）、时间价值占比低，**适合慢磨上涨**，对 theta 更耐受；权利金较高、杠杆较低。
  - ATM（平值）：delta ≈ 0.5，平衡型。
  - OTM（虚值）：权利金低、杠杆高，但需要更大涨幅才进入实值，对 theta 与慢磨最敏感——仅在强催化剂、预期较大涨幅时使用。
- **盈亏平衡价（长 call）**：`行权价 + 权利金`。判断：到期前标的能否合理涨破盈亏平衡价？盈亏平衡涨幅与第 3 节预期波动比较，并对照"涨慢于跌"取保守。

## 6. 风险回报比

- **最大亏损 = 权利金**（买方风险锁定，相对裸多/融资买入的核心优势）。
- 按**保守**目标位估算回报：`(目标价位下的 call 内在价值 − 权利金) / 权利金`，得到回报/风险倍数。
- 结合 Pre-mortem 的失败概率做粗略期望值判断：高 IV 买贵的 call + 慢磨涨势 + 平庸目标涨幅 = 负期望，再正确的方向也该放过。

## 7. F5 判定锚点

| 判定 | 标准 |
|------|------|
| ✅ 划算 | IV Rank 偏低（call 不贵）+ 保守目标涨幅仍显著超过预期波动 + 无临近财报 IV crush 敞口 + 风险回报比 ≥ 2:1 + 到期日 45-60 DTE（或略实值降 theta） |
| ⚠️ 勉强 | 单项不利（如 IV 中性偏高，或目标涨幅仅略超预期波动，或跨财报需防 crush），需更严格的入场点与退出纪律 |
| 🚨 不划算 | IV Rank 高（贵且易 crush）/ 预期波动已覆盖目标涨幅 / 风险回报比 < 1.5:1 / 被迫买临近财报的高 IV call → 降级为"观察（等期权时机）" |

**降级 ≠ 放弃**：F1 + 上涨引擎成立但 F5 不划算时，结论为"观察"——等 IV 回落、或等回调到更好入场价再买 call，而非否定做多逻辑本身。
