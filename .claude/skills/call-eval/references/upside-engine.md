# 上涨引擎：基本面向好与催化剂（Filter 2 + Filter 3）

Filter 2 与 Filter 3 共同构成"上涨引擎"——回答 **1-2 个月内是什么在推这只股票涨**。因为上涨是慢磨（楼梯式），本模型把催化剂从 short-eval 的"加速器"升格为准必要条件：**F2（基本面向好）与 F3（催化剂）至少居其一达标，否则慢磨的涨势会被 theta 拖死。** 每项判定须给具体数据，禁止用形容词代替证据。注意 F2 看的是"向好的轨迹"，不是 munger-eval 式的"长期伟大"。

## 1. 理论基础

- **盈余漂移 PEAD（Bernard & Thomas, 1989）**：财报超预期后，股价在随后**数周至数月**continue向超预期方向漂移——市场对好消息反应不足。这是 1-2 个月做多窗口里**最契合**的学术引擎。
- **盈利预测修正动量**：分析师上修盈利预测的股票，随后倾向跑赢（上修往往成串出现、反应不足）。
- **质量因子 / Quality Minus Junk（Asness, Frazzini & Pedersen）**：高质量（高盈利、成长、安全、稳定）股票系统性跑赢——做多标的应在质量维度得分高，避免被纯题材股反噬。
- **动量与基本面的结合**：技术动量（F1）+ 基本面/盈利动量（F2/F3）共振时，胜率与持续性更佳；只有技术动量而无基本面支撑的拉升，回撤风险高（归入 F4）。

## 2. F2-A：盈利动量与预测上修

- 盈利是否**加速**（增速的二阶导为正，而非仅维持）？
- 分析师盈利预测（本季/全年 EPS）近 1-3 个月是否持续上修？上修是否成串、幅度多大？
- 营收增速是否回升、订单/在手合同是否改善？

合格证据：连续多家上修、上修幅度显著、管理层上调指引。不合格："分析师看好"（无预测数字变化）。

## 3. F2-B：盈余漂移 PEAD（短窗口最强引擎）

最近一期财报：
- 是否**超预期**（EPS/营收 beat，且超预期幅度大）？
- 财报后股价是否正向跳空且**漂移尚未走完**（PEAD 可持续数周至数月）？
- 是否伴随指引上修（beat-and-raise 最强）？

PEAD 是本模型在 1-2 个月窗口里最理想的引擎之一：时间尺度天然匹配。但须与 F5 配合——若财报刚过、IV 已回落，反而是较好的买 call 时点（避开了 IV crush）；若下一份财报临近，则要防新的 IV 抬升与 crush。

## 4. F2-C：质量与利润率（避免纯故事股）

- 毛利率 / 经营利润率是否**扩张**？
- ROIC / ROE 是否健康且向上？经营现金流是否跟得上利润（避免应计虚增）？
- 资产负债是否稳健（区别于 short-eval 的困境标的）？

作用：把"基本面向好"与"纯情绪题材拉升"区分开。质量差但靠题材猛拉的，F2 不应给高分，且 F4 回调/泡沫风险要顶格警惕。

## 5. F2-D：戴维斯双击潜力

回答"如果涨，能涨多高"：当**盈利上修**与**估值倍数扩张**同时发生，涨幅是两者相乘：

```
涨幅 ≈ (EPS_new / EPS_old) × (PE_new / PE_old) − 1
```

例：EPS 上修 15%、PE 从 20 扩到 25（+25%）→ 股价 ≈ 1.15 × 1.25 − 1 = +44%。

但须正视不对称：估值扩张比压缩更"克制"（涨慢于跌），且高位易被增发盖帽（见 pullback-risk.md 稀释风险）。**双击的涨幅目标要设得比对称的双杀跌幅更保守。**

## 6. F3：催化剂清单与判定

逐个催化剂判定，并确认其落在期权到期日**之前**、方向利多、且尚未被充分定价：

| 催化剂类型 | 利多触发 | 注意 |
|-----------|---------|------|
| 财报 / 指引 | beat-and-raise、超预期 | ⚠️ IV crush 风险，见 option-structure.md |
| 新产品 / 订单 / 客户 | 重磅发布、大单、标杆客户 | 是否已被市场预期 |
| 资本运作 | 回购、分拆、并购、战投入股 | 回购规模与节奏 |
| 政策 / 行业 | 补贴、放松监管、景气数据 | 受益弹性是否真落到该公司 |
| 行业龙头带动 | 同业超预期的传导 | 二阶受益的确定性 |

**警惕"利好出尽"（sell the news）**：已被充分预期的催化剂，兑现日往往是阶段顶——这类催化剂 F3 不加分，反而在 F4 计为风险。

## 7. F2 评分锚点（0-10，越高=基本面引擎越强）

| 分数 | 标准 |
|------|------|
| 9-10 | 盈利加速 + 预测成串上修 + 最近财报 beat-and-raise 且 PEAD 在途 + 利润率扩张（多引擎共振） |
| 7-8 | 至少一项强引擎（如明确 PEAD，或连续显著上修）+ 质量健康 |
| 6 | 基本面确有改善但证据单一或刚开始 |
| 4-5 | 基本面平淡，上涨主要靠题材/情绪（"只涨不强"，单独不构成引擎） |
| 0-3 | 基本面在恶化或为纯故事股（不应据此做多） |

## 8. F3 评分锚点（0-10，越高=催化剂越强）

| 分数 | 标准 |
|------|------|
| 9-10 | 窗口内有明确、未充分定价、方向利多的硬催化剂（如临近 beat-and-raise 概率高、确定的资本运作） |
| 7-8 | 有较明确催化剂，但时间/幅度或定价程度存一定不确定 |
| 5-6 | 催化剂较软或部分已被预期 |
| 3-4 | 仅有模糊预期，或催化剂可能"利好出尽" |
| 0-2 | 窗口内无可识别催化剂（须靠 F2 基本面引擎独撑，且 F5 赔率与持有计划相应打折） |

**评分依据须对照锚点**：说明 F2/F3 各得多少、"上涨引擎"是否成立（F2 或 F3 ≥ 7）；两者皆 < 7 → 否决。
