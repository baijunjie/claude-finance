# 上升趋势确认标准（Filter 1）

Filter 1 的详细判定标准。核心：**只在确认的中期上升趋势中做多，绝不抄底、绝不追下降趋势。** 每一项判定都必须给出具体证据（价位、均线值、相对强弱数据），禁止用"走势强"之类形容词代替证据。

## 1. 理论基础

- **道氏理论（Dow Theory）**：上升趋势由连续的更高高点 + 更高低点定义；趋势一旦确立倾向于延续，直到出现明确反转信号；次级回调不改变主趋势。
- **横截面动量异象（Jegadeesh & Titman, 1993）**：过去 3-12 个月的"赢家"组合在随后数月continue跑赢——做多中期赢家在统计上有正期望。
- **时间序列动量 / 趋势跟踪（Moskowitz, Ooi & Pedersen, 2012）**：资产自身近 3-12 个月的回报方向对未来有预测力。
- **52 周新高异象（George & Hwang, 2004）**：接近 52 周新高的股票倾向于continue上涨（锚定效应使突破后惯性延续）。
- **移动平均规则（Faber, 2007）**：价格在长期均线（如 200 日）上方时持有多头，可改善风险调整后回报。

这些共同支撑本模型立场：**做多已在中期上升通道、甚至创新高的标的，比抄底反转风险低得多。**

## 2. 道氏理论：趋势结构判定

核心问题：**近 3-6 个月是否形成连续更高的高点 + 更高的低点？**

| 判定 | 标准 |
|------|------|
| ✅ 确认上升 | 至少 2 个依次抬高的波段高点 + 2 个依次抬高的波段低点；回调获支撑（前高/均线）后再创新高 |
| ⚠️ 转强未确认 | 刚突破重要平台/前高但尚未回踩确认，或低点开始抬高但高点未破 |
| ❌ 非上升 | 更低的高点/更低的低点（下降趋势），或高低点交错无方向（宽幅震荡） |

辅助确认：突破伴随放量、回调缩量（量价配合）；有效站上关键阻力（前期平台、颈线、整数关口）。

## 3. 均线与位置判定

- **价格位置**：收盘价是否在 200 日均线**上方**？距离多少百分比？（适度上方为健康；过度乖离需结合 F4 防追高回调）
- **均线排列**：50 日均线是否在 200 日均线上方（多头排列 / 金叉已发生）？均线是否向上发散？
- **52 周位置**：是否接近或创 52 周新高？（新高附近倾向continue上行——52 周新高异象）

合格的上升趋势通常满足：价 > 200 日线，且 50 日 > 200 日，且均线向上发散。

## 4. 相对强弱、动量与 52 周新高

- **相对大盘**：近 3 / 6 个月相对基准指数是否持续跑赢？
- **相对板块**：是否跑赢所属行业板块？（个股强 + 板块强 = 更强的做多环境）
- **动量形成窗口**：用 **3-6 个月**回报判断趋势方向，而非最近 1 个月（原因见第 5 节）。
- **新高质量**：放量突破创新高 > 缩量阴跌后的虚弱反弹。

## 5. 一个关键细节：短期反转 + 涨慢于跌的不对称

两个必须知道的事实：

1. **短期反转（1 个月内）**（Jegadeesh, 1990; Lehmann, 1990）：上月大涨的股票下月倾向于回调。含义：**判定趋势用中期窗口（3-6 个月 / 200 日均线），"上个月涨很多"本身不构成可追的上升趋势，反而可能是回调前兆。** 你持有的 1-2 个月窗口恰好落在短期反转高发区——这正是 F4 必须单列"追高回调风险"的理论原因，也支持"找点位平仓而非持有到期"。

2. **涨慢于跌的不对称**（杠杆效应 / 波动率不对称；恐惧强于贪婪）：上涨多为渐进爬升（楼梯），下跌常为暴力跳水（电梯）。含义：**做多即使方向对，达到目标位通常更慢**，theta 衰减的压力比做空更大——因此 F1 要求的趋势强度、F3 催化剂的存在、F5 的保守目标，三者共同对冲这个不对称。单纯"温和上行"而无催化剂的慢牛，往往跑不赢时间价值。

## 6. 反例：什么不算"确认的上升趋势"

以下情形 F1 一律判 ❌ 或 ⚠️，不得追多：
- **下降趋势中的反弹 / 抄底**：哪怕基本面好、估值便宜——下降趋势可持续，做多它是接刀（本模型明确否定）。
- **宽幅震荡 / 箱体**：无明确方向，call 会被 theta 慢慢磨掉。
- **单日/单周暴涨后的高点**：极度超买，技术性回调概率高（短期反转），应等回调企稳、趋势重新确认后再评估。
- **缩量虚弱反弹**：无量配合的上涨，持续性差，归入 F4 回调风险评估。

## 7. F1 判定锚点

| 判定 | 标准 |
|------|------|
| ✅ 通过 | 道氏结构确认上升（更高高低点）+ 价在 200 日线上方 + 50 日 > 200 日 + 近 3-6 个月跑赢大盘/板块（或创 52 周新高）；且当前非极度超买 |
| ⚠️ 有条件通过 | 趋势刚转强（如初次突破平台/前高，或均线刚金叉）但结构未完全确认——须写明确认信号与价位（如"回踩 X 价不破并放量上行后确认"） |
| ❌ 不通过 | 处于下降趋势、宽幅震荡，或仅为下跌后的超跌反弹/反抽 → 结论锁定"放弃（趋势不支持）" |
