# 做多适配度评估（Call Eval）

用一套可证伪的标准评估一只股票是否适合**买入看涨期权做多**：**顺着已确认的上升趋势、做多有上涨引擎的标的，在 1-2 个月窗口内找点位平仓。** 评估的目的不是找到"它会涨"的理由，而是穷尽"这笔做多会亏掉权利金"的理由——趋势与上涨引擎双必要、且期权赔率划算才值得出手。

## 核心范式：右侧做多，不抄底，并正视"涨慢于跌"的不对称

本模型**不抄底、不预测反转**（在上升趋势确认前买入是抄底/接刀，1-2 个月期权窗口里风险过高）。它只在**趋势已经确认向上**时，顺着已发生的强势做多。

**关键不对称（本模型不是 short-eval 的纯镜像）**：上涨在期权买方视角下系统性**慢于、弱于**下跌——
- **波动率杠杆效应**（Black 1976；EGARCH/GJR-GARCH）：下跌放大波动率、上涨压低波动率；"股票走楼梯上去，坐电梯下来"。
- **恐惧强于贪婪**（损失厌恶）：恐慌抛售集中而暴力，上涨多为渐进爬升。
- **股权稀释**（新股发行之谜 Loughran-Ritter；股权择时 Baker-Wurgler）：公司倾向高位增发，给涨势盖帽。

对买 call 的直接含义：**即使方向看对，慢磨的涨势经常跑不赢 theta 衰减。** 因此本模型相对 short-eval 做了三处修正：**① 催化剂从"加速器"升格为准必要条件**（慢磨需要催化剂压缩时间线）；**② 增发/稀释列为专属红旗**；**③ 目标涨幅与赔率门槛更保守。**

**两个必要条件：**
- 趋势(F1)向上 **且** 上涨引擎(F2 基本面向好 ∨ F3 催化剂，至少居其一)成立。
- 只涨不强（纯题材/情绪拉升，无基本面也无催化剂）→ 泡沫随时崩，**不做**。
- 只好不涨（基本面好但仍在下降/震荡趋势）→ 价值陷阱，1-2 个月窗口等不到市场认可，**不做**。

**宏观层（F0）的左侧例外**：不抄底（不抓个股拐点），但允许**带护栏的左侧宏观判断**——宏观可作顺风/逆风确认，也可作论点驱动与催化剂（risk-on / 宽松 = 做多顺风）。但有铁律：**宏观单独不能覆盖 F1，个股趋势仍是硬必要条件**（宏观+趋势共振才行）。同时，宏观也可能**终结一个已确认的上升趋势**（如鹰派意外/信用事件引爆 risk-off），这一风险须进 F0 与 Pre-mortem——尤其因"涨慢于跌"，顶风做多的慢磨涨势更易夭折。

## 评估原则

- **逆向优先**：先问"什么会让这笔做多亏钱"（趋势反转、追高回调、利好出尽、IV crush、theta 衰减、增发砸盘），再问"它为什么会涨"。
- **否决制，非加权平均**：任一必要条件不及格即整体否决，高分项不能弥补低分项。
- **证据驱动**：每个结论必须有具体证据（价格结构、财务数据、催化剂日历、期权链报价），禁止用形容词代替证据。"走势很强"不是证据，"连续 3 个月更高的高点和更高的低点、价在 200 日均线上方 15% 且放量突破前高"才是。
- **theta 是更凶的敌人**：因上涨慢磨，1-2 个月的 call 比 put 更怕时间衰减——没有催化剂支撑的"慢慢爬升"会被时间价值吃掉，宁可放过。
- **承认不确定**："趋势不明 / 无上涨引擎，放弃"是合法且体面的结论，比强行追高更有价值。

## 工作流程

### 第 0 步：数据收集

评估开始前，收集以下数据（来源优先级：用户提供的材料 > 联网搜索行情/财报/期权数据 > 模型已有知识，并注明数据截止时间）：

- **宏观环境（F0 用）**：大盘指数趋势与宽度、利率/央行政策与流动性、收益率曲线、信用利差（HY OAS）、VIX 制度、美元与大宗、板块/风格轮动；窗口内宏观日历（FOMC、CPI/PCE、NFP、央行会议等）；标的与大盘的相关性/beta
- **价格与趋势**：近 12 个月日线走势、52 周高/低点、相对 50/200 日均线位置、近 3/6 个月相对大盘与板块的相对强弱、突破与成交量结构
- **基本面（上涨引擎判定用）**：近 5-8 季营收/毛利率/经营利润率/盈利趋势、盈利是否加速、分析师盈利预测上修/下修、最近财报是否超预期及股价反应（PEAD）、ROIC/ROE 趋势
- **稀释风险**：在外可转债、ATM 增发计划、增发/配股历史、即将到来的限售解禁、股权激励行权稀释、股本变化趋势
- **估值**：P/E、P/S、EV/EBIT 及其相对历史与同行分位（高估值是回调放大器）
- **催化剂日历**：未来 1-2 个月的财报日、指引、产品发布、订单、并购、政策、行业数据节点
- **拥挤度**：近期涨幅与资金流入、是否散户抱团/meme、看涨情绪指标、机构持仓拥挤度
- **期权链**：目标到期月各行权价的报价、隐含波动率（IV）、IV rank/percentile、历史波动率（HV）、put-call skew、各 greeks（尤其 theta、delta、vega）

数据不足时明确标注"数据缺口 ❓"，不要编造。期权与稀释数据缺失会直接削弱 F4/F5 的可靠性，须显著标注。

### 第 0.5 步：宏观环境过滤器（Filter 0，在 F1 之前执行）

读取 [references/macro-regime.md](references/macro-regime.md)，自上而下先判宏观大势，承担三个角色：

- **顺风/逆风确认**：判断宏观制度是否支持做多方向——risk-on / 宽松 / 信用利差收窄 / VIX 低位 = ✅ 顺风；risk-off / 紧缩 / 信用利差走阔 / VIX 抬升 = 🚨 逆风。**强逆风（明确反向 + 个股高 beta）→ 否决或降级**，因顶风做多的慢磨涨势更易夭折。
- **左侧宏观引擎（可选，带护栏）**：允许把宏观拐点（降息周期、政策刺激）作为论点驱动与催化剂（喂给 F3），但必须锚定到窗口内带截止日的触发 + 跨资产确认 + 减仓/更长 DTE；且**个股 F1 趋势仍须至少初步确认——宏观单独不能覆盖 F1 否决（不抄底）**。
- **趋势终结风险**：评估窗口内是否有宏观事件可能**终结当前上升趋势**（鹰派意外、流动性收紧、信用事件引爆 risk-off），喂给第 6 步 Pre-mortem；避免在 FOMC/CPI 等宏观事件前追高买 call。

判定三档：**✅ 顺风 / ⚠️ 中性 / 🚨 逆风**。中性时 F0 不加不减，按 F1-F5 推进。

### 第 1 步：上升趋势确认过滤器（Filter 1，必要条件）

读取 [references/trend-confirmation.md](references/trend-confirmation.md)，按其中标准判定标的是否处于**确认的中期上升趋势**：

- 道氏理论结构：是否形成连续更高的高点 + 更高的低点？
- 均线与位置：价是否在 200 日均线**上方**、且 50 日在 200 日上方（多头排列）？
- 相对强弱 / 动量：近 3-6 个月是否持续跑赢大盘与板块？是否创 52 周新高（新高异象）？
- 回调风险预判：当前是否处于超买（短期反转风险）、追高位置？（详见 F4）

判定分三档：**通过 / 有条件通过 / 不通过**。"有条件通过"用于趋势刚转强、结构未完全确认（如刚突破平台但未回踩确认）的情形，必须写明要求确认的具体信号与价位。

**F1 不通过（处于下降趋势或宽幅震荡）→ 最终结论锁定为"放弃（趋势不支持）"**，并写明 F1 是首要否决项；其余各层照常完成作为证据链。**哪怕基本面再好、催化剂再多，下降趋势中一律不追多（不抄底）。**

### 第 2 步：基本面向好过滤器（Filter 2，"上涨引擎"组件之一）

读取 [references/upside-engine.md](references/upside-engine.md)，判定基本面是否在**改善并能驱动上涨**（注意是"向好的轨迹"，不是 munger 式的"长期伟大"）：

- **盈利动量**：盈利是否加速增长？分析师盈利预测是否持续上修？
- **盈余漂移 PEAD**：最近财报是否超预期、且股价正向反应未走完？（Bernard-Thomas：超预期后股价倾向continue漂移数周至数月）
- **质量与利润率**：利润率是否扩张？ROIC/现金流是否健康（避免纯故事股）？
- **戴维斯双击潜力**：盈利上行 × 估值扩张是否在途？
- 评分 0-10，与 F3 共同决定"上涨引擎"是否成立（见评分规则）。

### 第 3 步：催化剂过滤器（Filter 3，"上涨引擎"组件之二，已升格为准必要）

判定 1-2 个月窗口内是否有可**驱动上涨**的事件——因上涨慢磨，催化剂在本模型比在 short-eval 中重要得多，它负责把上涨时间线压进期权窗口：

- 候选催化剂：财报超预期/指引上修、新产品或订单、并购或回购、政策利好、行业景气数据、龙头带动
- 对每个催化剂判定：时间是否落在期权到期日**之前**？方向是否明确利多？市场是否已充分定价（已 priced in 的不加分，且要防"利好出尽"，见 F4）？
- **催化剂 = 财报时务必警惕 IV crush**（见 F5）：财报前 IV 抬升，财报后即使股价上涨 IV 也崩塌，临近财报追 call 是经典陷阱。
- 评分 0-10，与 F2 共同决定"上涨引擎"。

### 第 4 步：追高回调 / 利好出尽 / 稀释风险过滤器（Filter 4，逆向层）

读取 [references/pullback-risk.md](references/pullback-risk.md)，排查"做多者如何被打爆"：

- **追高回调 / 超买反转**：1 个月内的短期反转效应（多头版）——当前是否严重超买（RSI 极高、连续大阳线、乖离过大），随时技术性回调？
- **利好出尽（sell the news）**：催化剂是否已被充分预期、兑现即见顶？
- **拥挤多头**：是否人人满仓看多、散户抱团/meme？拥挤的多头一遇利空踩踏式回吐。
- **稀释 / 砸盘风险（call-eval 专属）**：高位增发/配股、ATM 计划、可转债转股、限售解禁、大股东减持——直接给涨势盖帽甚至砸盘。
- 评分越高越安全；触发严重风险（顶部派发、巨额增发在途、极度超买）→ 否决或降级。

### 第 5 步：期权结构与赔率过滤器（Filter 5，把判断翻译成"这笔 call 划不划算"）

读取 [references/option-structure.md](references/option-structure.md)，做**定性 + 关键指标**评估（不做精确 Black-Scholes 定价）：

- **IV 水平与 skew**：IV rank / percentile 是否过高？利用 put-call skew——同等虚值下 call 的 IV 通常低于 put（对买方有利），但别被高 IV 题材股反噬
- **预期波动 vs 目标涨幅**：用预期波动 ≈ 股价 × IV × √(DTE/365) 估算到期前隐含波动幅度，对比你预期的上涨幅度——**目标涨幅须设得保守（楼梯式上涨），且要显著超过隐含波动才有赔率**
- **Theta 与到期日选择**：因上涨慢磨，倾向买 ~45-60 DTE 或略长、必要时略实值（ITM）以降低 theta 损耗；在最后 ~21 天 theta 加速前平仓
- **行权价与盈亏平衡**：ATM/略 OTM；盈亏平衡价 = 行权价 + 权利金，到期前能否合理涨破？
- **风险回报比**：最大亏损 = 权利金；按保守目标位估算回报/权利金倍数
- 赔率不划算（IV 太贵、预期波动已覆盖目标涨幅、风险回报比过低）→ 结论降级为"观察（等期权时机）"。

### 第 6 步：逆向 Pre-mortem 与退出计划

读取 [references/pullback-risk.md](references/pullback-risk.md) 的 Pre-mortem 与退出计划部分，执行：

1. **Pre-mortem**：假设期权到期时这笔做多亏光权利金，写出 3-5 条最可能的原因（趋势反转、**宏观逆转终结上升趋势（F0 识别的宏观事件，如鹰派意外/信用事件引爆 risk-off）**、追高回调、利好出尽、IV crush、催化剂落空、theta 衰减跑赢涨幅、增发砸盘），按概率排序，每条给出**估算概率区间**并满足：① 概率与排序一致；② 用宽区间表达不确定性；③ 与各层风险判定口径（含 F0）互相校验。
2. **退出计划**（对应"不持有到期、找点位平仓"）：必须明确写出
   - **止盈**：目标价位/标的涨幅 → 平仓点（如标的涨至阻力位、涨幅达预期波动的 X%）；可分批
   - **止损**：标的反向跌破关键支撑（如失守 50 日均线 / 跌回突破平台内）或权利金回撤达 X% 时认赔
   - **时间止损**：到期前 ~21 天若论点未兑现则离场（避开 theta 加速）

### 第 7 步：输出评分卡 + 做多备忘录

按 [assets/memo-template.md](assets/memo-template.md) 模板生成备忘录，保存到当前工作目录 `output/call-eval/<标的名>-<日期>.md`（目录不存在时先创建）。

**判定标识（全文统一使用，提高辨识度）：**

| Emoji | 含义 | 用在哪里 |
|-------|------|---------|
| ✅ | 确认有利做多 / 确认通过（证据充分的正面判定） | 上升趋势确认、基本面向好、催化剂存在且利多、回调风险低、赔率划算 |
| 🚨 | 确认不利 / 否决项（证据充分的负面判定） | 下降趋势、顶部派发、巨额增发在途、IV crush 陷阱、触发否决/降级的分项 |
| ⚠️ | 存疑（证据不足或方向不明，结论可被新证据翻转） | 趋势刚转强、上涨引擎证据不足、有条件通过 |
| ❓ | 数据缺口（数据不全、待核实，影响判定可靠性） | 引用估算值/未核实数据处、第九节数据缺口列表（期权/稀释数据缺失常见） |
| ❌ | 不通过 / 无（明确的"没有"） | 趋势不向上、无上涨引擎、无催化剂、赔率不成立 |

使用规则：结论速览表、上涨引擎表、回调风险清单的判定列**必须**带标识；正文中的关键判定（趋势结构、盈利上修/PEAD、IV rank、风险回报比）在判定词后紧跟标识；不要在叙述性文字中滥用，每个标识只标判定本身。

**评分与结论规则（否决制，F1 必要 + 上涨引擎(F2∨F3)必要）：**

| 过滤器 | 评分 | 及格线 |
|--------|------|--------|
| F0 宏观环境 | 顺风 / 中性 / 逆风 | **强逆风（明确反向 + 高 beta）→ 否决或降级**；中性不加不减；左侧引擎不可单独覆盖 F1 |
| F1 上升趋势确认 | 通过 / 有条件通过 / 不通过 | **不通过（非上升趋势）→ 结论锁定"放弃（趋势不支持）"** |
| F2 基本面向好 | 0-10 | 见"上涨引擎"组合规则 |
| F3 催化剂 | 0-10 | 见"上涨引擎"组合规则 |
| **上涨引擎（F2∨F3）** | F2 ≥ 7 或 F3 ≥ 7 至少一项 | **两者皆 < 7 → 否决（无引擎，慢磨会被 theta 拖死）** |
| F4 回调/稀释风险（越高越安全） | 0-10 | < 5 → 降级为"观察"；顶部派发/巨额增发在途 → 否决 |
| F5 期权赔率 | 划算 / 勉强 / 不划算 | 不划算 → 降级为"观察（等期权时机）" |

- F0 非强逆风 + F1 通过（或有条件通过且确认） + 上涨引擎成立（F2 或 F3 ≥ 7，两者皆强为最佳） + F4 ≥ 6 + F5 划算：**买入**（值得建仓买 call）
- 论点成立（F1 + 引擎过）但 F0 逆风 / F4 偏高风险 / F5 赔率不划算（如 IV 太贵）：**观察**（等宏观转向、回调入场或更好期权时机）
- F0 强逆风 / F1 不通过 / 上涨引擎不成立（F2、F3 皆弱）/ F4 顶部派发或巨额增发在途：**放弃**，写明单一否决原因
- 注意区分用词：F0 强逆风/F1/上涨引擎/F4 严重风险不及格是"**否决**"，F0 逆风、F4 中等风险与 F5 不划算是"**降级**"，结论速览表中统一填入"否决/降级原因"一行
- 评分必须附证据引用；没有证据支撑的分项最高给 5 分
- F2/F3/F4 每层末尾必须附"**评分依据**"，对照各 reference 的评分锚点说明为何给该分
